## Картинка — это таблица чисел

Для компьютера изображение — массив чисел: высота × ширина × каналы. В чёрно-белой картинке один канал (яркость от 0 до 255), в цветной — три (красный, зелёный, синий). Фото 224 × 224 пикселя — это 150 528 чисел.

Если подать такую картинку в полносвязную сеть, получится беда:

- параметров слишком много: один слой на 1000 нейронов — 150 миллионов весов;
- сеть не понимает, что кошка в левом углу и кошка в правом — одно и то же: каждый пиксель для неё отдельный признак.

**Свёрточные сети (CNN)** решают обе проблемы.

## Свёртка

**Свёртка** — небольшое окно (**ядро**, или фильтр, обычно 3 × 3), которое скользит по картинке. В каждом положении значения под окном умножаются на веса ядра и складываются. Получается новая картинка — **карта признаков**.

Начнём с одномерного случая. Ядро `[-1, 1]` считает разницу соседних значений и поэтому «загорается» на скачках:

```python
signal = np.array([3, 3, 3, 8, 8, 8, 2, 2])
kernel = np.array([-1, 1])
print(np.correlate(signal, kernel, mode="valid"))    # [ 0  0  5  0  0 -6  0]
```

> 💡 В нейросетях «свёрткой» называют именно эту операцию — скольжение окна без переворота ядра (в математике она называется взаимной корреляцией). Поэтому здесь `np.correlate`, а не `np.convolve`: последний переворачивает ядро.

В двумерном случае окно скользит по строкам и столбцам. Ядро ниже реагирует на **вертикальные границы** — переход от тёмного к светлому:

```python
image = np.array([
    [0, 0, 0, 9, 9, 9],
    [0, 0, 0, 9, 9, 9],
    [0, 0, 0, 9, 9, 9],
    [0, 0, 0, 9, 9, 9],
])
kernel = np.array([
    [-1, 0, 1],
    [-1, 0, 1],
    [-1, 0, 1],
])
h, w = image.shape[0] - 2, image.shape[1] - 2
out = np.zeros((h, w), int)
for i in range(h):
    for j in range(w):
        out[i, j] = (image[i:i + 3, j:j + 3] * kernel).sum()
print(out)
```

Главная идея CNN: веса ядер **не задаются вручную, а обучаются**. Первые слои сами находят границы и пятна, следующие собирают из них текстуры и детали (глаз, колесо), последние — целые объекты. Одно и то же ядро применяется по всей картинке, поэтому параметров мало, а объект распознаётся в любом месте.

## Шаг, дополнение, пулинг

- **шаг (stride)** — на сколько пикселей сдвигается окно; шаг 2 уменьшает карту вдвое;
- **дополнение (padding)** — рамка из нулей вокруг картинки, чтобы размер не уменьшался;
- размер выхода: `(W − K + 2P) / S + 1`, где W — размер входа, K — ядра, P — дополнение, S — шаг;
- **пулинг (pooling)** — сжатие карты: из каждого окна 2 × 2 берут максимум (**max pooling**). Сеть становится устойчивее к небольшим сдвигам и считает быстрее.

```python
fmap = np.array([
    [1, 3, 2, 0],
    [4, 6, 1, 1],
    [0, 2, 9, 5],
    [1, 1, 3, 7],
])
pooled = fmap.reshape(2, 2, 2, 2).max(axis=(1, 3))   # максимум в каждом окне 2×2
print(pooled)
```

## Архитектура CNN

```text
картинка → [свёртка → ReLU → пулинг] × несколько раз → выпрямление → полносвязные слои → softmax
```

Число каналов растёт с глубиной (32 → 64 → 128 фильтров), а размер карт уменьшается. Вехи: LeNet (1998, цифры на чеках), AlexNet (2012, прорыв на ImageNet), ResNet (2015, сотни слоёв благодаря «обходным» связям).

У свёрточного слоя `C_in` входных каналов и `F` фильтров размера `K × K`. Параметров у него `F × (K × K × C_in) + F`, и это число не зависит от размера картинки.

```py
from tensorflow import keras

model = keras.Sequential([
    keras.layers.Input(shape=(64, 64, 3)),
    keras.layers.Conv2D(32, 3, activation="relu", padding="same"),
    keras.layers.MaxPooling2D(2),
    keras.layers.Conv2D(64, 3, activation="relu", padding="same"),
    keras.layers.MaxPooling2D(2),
    keras.layers.Flatten(),
    keras.layers.Dense(64, activation="relu"),
    keras.layers.Dense(3, activation="softmax"),     # три класса
])
```

## Перенос обучения

Обучать CNN с нуля нужно на миллионах картинок. На практике берут сеть, уже обученную на огромном наборе (ImageNet), **замораживают** её свёрточные слои — они уже умеют видеть границы, текстуры, формы — и дообучают только последние слои на своих сотнях или тысячах картинок. Это **перенос обучения (transfer learning)**.

```py
base = keras.applications.ResNet50(weights="imagenet", include_top=False, pooling="avg")
base.trainable = False
model = keras.Sequential([base, keras.layers.Dense(2, activation="softmax")])   # «брак / норма»
```

## Задачи компьютерного зрения

| Задача | Ответ сети | Пример |
|---|---|---|
| классификация | один класс на картинку | брак или норма на фото изделия |
| детекция объектов | рамки и классы всех объектов (YOLO) | товары на полке, люди в кадре |
| сегментация | класс каждого пикселя | границы дефекта, разметка дорог |
| распознавание текста (OCR) | текст на изображении | чеки, накладные, документы |

Для аналитика это источник новых данных: число покупателей по камерам, наличие товара на полке, доля брака на конвейере, данные из сканов документов.

## Шпаргалка

| Понятие | Суть |
|---|---|
| ядро (фильтр) | маленькое окно весов, скользит по картинке |
| карта признаков | результат свёртки |
| размер выхода | `(W − K + 2P) / S + 1` |
| max pooling | максимум в окне, сжатие |
| параметры свёртки | `F × K × K × C_in + F` |
| перенос обучения | готовая сеть + дообучение последних слоёв |
