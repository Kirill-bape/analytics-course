## От распознавания к созданию

Все модели до этого урока **различали**: класс, число, тему. **Генеративные модели** создают новое: тексты, изображения, звук, синтетические таблицы. Они выучивают, как устроены данные, и умеют порождать похожие примеры.

| Семейство | Идея | Где |
|---|---|---|
| автокодировщики (AE, VAE) | сжать данные в короткий код и восстановить обратно | сжатие, поиск аномалий, генерация вариаций |
| GAN | генератор и дискриминатор соревнуются | реалистичные лица, стили, синтетические данные |
| диффузионные модели | учатся шаг за шагом убирать шум | Stable Diffusion, Kandinsky, Midjourney |
| языковые модели (LLM) | предсказывают следующий токен | ChatGPT, Claude, YandexGPT, GigaChat |

## Автокодировщик

**Автокодировщик** — сеть из двух частей: **кодировщик** сжимает вход в короткий вектор (**латентное представление**), а **декодировщик** восстанавливает из него вход. Сеть учится так, чтобы восстановление было как можно ближе к оригиналу.

Линейный автокодировщик делает то же, что PCA: оставляет главные компоненты. Посмотрим на данных производства:

```python
p = production.dropna(subset=["downtime_min"])[["planned_units", "produced_units", "defect_units", "downtime_min"]]
Z = ((p - p.mean()) / p.std()).to_numpy()

U, S, Vt = np.linalg.svd(Z, full_matrices=False)
for k in [1, 2, 3]:
    code = Z @ Vt[:k].T            # кодировщик: 4 признака → k чисел
    restored = code @ Vt[:k]       # декодировщик: k чисел → 4 признака
    print(f"код из {k}: ошибка восстановления {np.mean((Z - restored) ** 2):.4f}")
```

Полезное применение — **поиск аномалий**: модель, обученная на нормальных сменах, плохо восстанавливает необычные. Большая ошибка восстановления — повод проверить смену. **Вариационный автокодировщик (VAE)** делает латентное пространство «гладким»: из случайной точки этого пространства декодировщик порождает правдоподобный новый пример.

## GAN: соревнование двух сетей

**Генеративно-состязательная сеть (GAN)** — две сети:

- **генератор** превращает случайный шум в картинку и старается обмануть соперника;
- **дискриминатор** отличает настоящие картинки от поддельных.

Они обучаются по очереди: дискриминатор учится ловить подделки, генератор — делать подделки правдоподобнее. В итоге генератор создаёт реалистичные изображения. GAN капризны в обучении, и для картинок их во многом вытеснили диффузионные модели.

## Диффузионные модели

Идея: берём картинку и шаг за шагом добавляем шум, пока не останется чистый шум. Сеть учат решать обратную задачу — по зашумлённой картинке предсказывать шум, который нужно убрать. Генерация — это путь от случайного шума через десятки шагов «очистки» к изображению. Текстовый запрос подаётся как условие на каждом шаге: так работают Stable Diffusion и Kandinsky.

## Как языковая модель выбирает слово

На каждом шаге LLM выдаёт логиты для всех токенов словаря, а softmax превращает их в вероятности. Следующий токен **выбирают случайно** из этого распределения, и способ выбора сильно влияет на текст:

- **температура** `T`: перед softmax логиты делят на `T`. Маленькая `T` (0,2) — почти всегда самый вероятный токен, ответы предсказуемые; большая (1,5) — больше разнообразия и риска бессмыслицы;
- **top-k / top-p**: выбирать только среди k самых вероятных токенов (или самых вероятных с суммарной вероятностью p), отбросив «хвост».

```python
logits = np.array([2.0, 1.0, 0.2, -1.0])     # «доставка», «оплата», «возврат», «погода»
for T in [0.3, 1.0, 2.0]:
    z = logits / T
    p = np.exp(z) / np.exp(z).sum()
    print(f"T = {T}:", np.round(p, 3))
```

## Ограничения и правила работы

- **Галлюцинации**: модель уверенно пишет правдоподобную неправду — несуществующие цифры, ссылки, функции. Факты, числа и код **всегда проверяются**.
- Модель не знает событий после даты своего обучения и не видит твоих данных, пока их ей не дали.
- **RAG (retrieval-augmented generation)**: документы компании режут на фрагменты, превращают в эмбеддинги, по вопросу находят похожие фрагменты и передают их модели вместе с вопросом. Так ответы опираются на реальные источники.
- **Конфиденциальность**: не отправляй персональные и коммерческие данные во внешние сервисы без разрешения компании.
- Сгенерированные изображения и тексты могут нарушать авторские права и вводить в заблуждение — их помечают и используют ответственно.

## Генеративный ИИ в работе аналитика

- черновики SQL и кода, объяснение чужих запросов — с проверкой результата на данных;
- разметка и классификация тысяч отзывов и обращений;
- суммаризация интервью и исследований пользователей;
- синтетические данные для тестов, когда реальные нельзя использовать.

Главное правило: модель — помощник, а ответственность за цифры и выводы остаётся на аналитике.

## Шпаргалка

| Понятие | Суть |
|---|---|
| автокодировщик | сжать → восстановить; ошибка восстановления ловит аномалии |
| VAE | гладкое латентное пространство для генерации |
| GAN | генератор против дискриминатора |
| диффузия | генерация как пошаговое удаление шума |
| температура | логиты / T: меньше — предсказуемее, больше — разнообразнее |
| top-k / top-p | выбор только из самых вероятных токенов |
| галлюцинации | уверенная неправда — проверять факты |
| RAG | поиск по своим документам + генерация ответа |
