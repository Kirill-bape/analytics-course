## Как сеть учится

Обучение нейросети — тот же градиентный спуск, что и у логистической регрессии, только параметров намного больше:

1. **прямой проход**: прогнать примеры через сеть и получить предсказания;
2. **функция потерь**: посчитать, насколько предсказания плохи;
3. **обратный проход (backpropagation)**: посчитать градиент потерь по каждому весу;
4. **шаг оптимизатора**: сдвинуть веса против градиента.

## Функции потерь

| Задача | Потери | Формула |
|---|---|---|
| регрессия | **MSE** | среднее `(y − ŷ)²` |
| два класса | **бинарная кросс-энтропия (log-loss)** | среднее `−[y·ln p + (1 − y)·ln(1 − p)]` |
| много классов | **кросс-энтропия** | `−ln(p правильного класса)` |

Кросс-энтропия сильно штрафует **уверенные ошибки**: предсказать 0,01 для того, что случилось, — потеря 4,6, а предсказать 0,5 — всего 0,69.

## Градиентный спуск и скорость обучения

```python
# минимизируем f(w) = (w − 3)², производная f'(w) = 2(w − 3)
for lr in [0.01, 0.1, 0.5, 1.1]:
    w = 0.0
    for step in range(20):
        w -= lr * 2 * (w - 3)
    print(f"скорость {lr}: w = {w:.3f}")
```

- слишком маленькая скорость — обучение ползёт;
- подходящая — быстро приходит к минимуму;
- слишком большая — «перепрыгивает» минимум, и веса улетают в бесконечность.

## Обратное распространение ошибки

Сеть — это вложенные функции: `потери(выход(скрытый(вход)))`. Градиент по весам первого слоя считают по **правилу цепочки**: ошибку выхода «протягивают» назад слой за слоем, умножая на производные. Для сигмоиды производная — `h · (1 − h)`.

```python
def sig(z):
    return 1 / (1 + np.exp(-z))

X = np.array([[0, 0], [0, 1], [1, 0], [1, 1]], float)
y = np.array([[0], [1], [1], [0]], float)           # XOR

rng = np.random.default_rng(0)
W1, b1 = rng.normal(0, 1, (2, 4)), np.zeros(4)     # 2 входа → 4 скрытых нейрона
W2, b2 = rng.normal(0, 1, (4, 1)), np.zeros(1)     # 4 скрытых → 1 выход

for epoch in range(5000):
    h = sig(X @ W1 + b1)                  # прямой проход
    out = sig(h @ W2 + b2)
    d_out = (out - y) / len(X)            # градиент кросс-энтропии по входу выходного нейрона
    dW2, db2 = h.T @ d_out, d_out.sum(axis=0)
    d_h = (d_out @ W2.T) * h * (1 - h)    # ошибка, протянутая на скрытый слой
    dW1, db1 = X.T @ d_h, d_h.sum(axis=0)
    W1 -= dW1; b1 -= db1; W2 -= dW2; b2 -= db2   # шаг со скоростью 1

print(np.round(out.ravel(), 3))
```

В Keras и PyTorch всё это делается автоматически: фреймворк сам строит граф вычислений и считает градиенты (**автоматическое дифференцирование**).

## Мини-батчи и эпохи

На миллионах примеров считать градиент по всем данным сразу слишком дорого. Данные делят на **мини-батчи** (обычно 32–512 примеров), и веса обновляют после каждого батча. **Эпоха** — один проход по всем данным. Шум от случайных батчей даже помогает: сеть меньше застревает в неудачных местах.

## Оптимизаторы

| Оптимизатор | Идея |
|---|---|
| SGD | шаг против градиента по мини-батчу |
| SGD + momentum | «инерция»: шаг учитывает предыдущие шаги, меньше дёргается |
| RMSprop | своя скорость для каждого веса по размеру его градиентов |
| **Adam** | momentum + адаптивная скорость; разумный выбор по умолчанию |

## Борьба с переобучением

У сетей огромное число параметров, и они легко переобучаются. Признак — потери на **валидации** перестают падать и начинают расти, хотя на обучении продолжают снижаться.

- **ранняя остановка (early stopping)**: остановить обучение, если валидационные потери не улучшаются N эпох подряд (**терпение**, patience), и вернуть лучшие веса;
- **dropout**: на каждом шаге обучения случайно «выключать» часть нейронов, чтобы сеть не полагалась на отдельные связи;
- **L2-регуляризация**: штраф за большие веса;
- **больше данных** и **аугментация** (повороты и сдвиги картинок).

```py
from tensorflow import keras

model = keras.Sequential([
    keras.layers.Input(shape=(20,)),
    keras.layers.Dense(64, activation="relu"),
    keras.layers.Dropout(0.3),
    keras.layers.Dense(1, activation="sigmoid"),
])
model.compile(optimizer=keras.optimizers.Adam(learning_rate=1e-3),
              loss="binary_crossentropy", metrics=["AUC"])
stop = keras.callbacks.EarlyStopping(monitor="val_loss", patience=3, restore_best_weights=True)
history = model.fit(X_train, y_train, validation_split=0.2, epochs=100, batch_size=64, callbacks=[stop])
```

## Шпаргалка

| Понятие | Суть |
|---|---|
| прямой / обратный проход | предсказание / градиенты |
| MSE, кросс-энтропия | потери для регрессии / классификации |
| скорость обучения | размер шага: мала — медленно, велика — расходится |
| мини-батч, эпоха | порция примеров / проход по всем данным |
| Adam | оптимизатор по умолчанию |
| early stopping, dropout | защита от переобучения |
