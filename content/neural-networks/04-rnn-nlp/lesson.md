## Тексты — тоже данные

Отзывы, обращения в поддержку, поисковые запросы, описания товаров — огромный источник информации для аналитика. Чтобы модель могла работать с текстом, его нужно превратить в числа.

## Мешок слов и TF-IDF

Самый простой способ — **мешок слов (bag of words)**: посчитать, сколько раз каждое слово встречается в тексте. Порядок слов теряется, но для многих задач (тематика, тональность) этого хватает.

```python
from collections import Counter

reviews = [
    "доставка быстрая товар отличный",
    "товар пришёл с браком доставка долгая",
    "отличный товар рекомендую",
]
words = " ".join(reviews).split()
print(Counter(words).most_common(4))
```

**TF-IDF** уточняет мешок слов: слово важно для документа, если часто встречается **в нём** (TF — term frequency), но редко — **в других** документах (IDF — inverse document frequency):

`IDF(слово) = ln(N / число документов со словом)`

Слова вроде «товар», которые есть почти везде, получают маленький вес, а редкие и характерные («брак») — большой.

## Эмбеддинги: смысл как координаты

**Эмбеддинг** — вектор из десятков или сотен чисел, который нейросеть выучивает для каждого слова (или целого текста) так, чтобы близкие по смыслу слова оказались рядом. Близость измеряют **косинусной мерой**: косинус угла между векторами, от −1 до 1.

`cos(a, b) = a · b / (|a| · |b|)`

```python
emb = {
    "доставка": np.array([0.9, 0.1, 0.0]),
    "курьер":   np.array([0.8, 0.2, 0.1]),
    "оплата":   np.array([0.1, 0.9, 0.1]),
    "карта":    np.array([0.2, 0.8, 0.0]),
}

def cos(a, b):
    return a @ b / (np.linalg.norm(a) * np.linalg.norm(b))

for w in ["курьер", "оплата", "карта"]:
    print("доставка ~", w, round(cos(emb["доставка"], emb[w]), 3))
```

С эмбеддингами можно искать похожие отзывы, кластеризовать обращения по смыслу, находить дубликаты товаров и строить **семантический поиск**: найти документы по смыслу, а не по совпадению слов. Знаменитое свойство word2vec: `король − мужчина + женщина ≈ королева`. Направления в пространстве эмбеддингов несут смысл.

## Рекуррентные сети

В тексте важен порядок: «не плохо» и «плохо, не» — разные вещи. **Рекуррентная сеть (RNN)** читает последовательность слово за словом и хранит **скрытое состояние** `h` — «память» о прочитанном:

`hₜ = tanh(Wₓ · xₜ + Wₕ · hₜ₋₁ + b)`

Одни и те же веса применяются на каждом шаге. Проблема простых RNN — память короткая: градиенты затухают на длинных текстах. **LSTM** и **GRU** добавили «вентили», которые решают, что помнить и что забыть. Долгие годы они были стандартом для текстов, речи и временных рядов.

## Внимание и трансформеры

В 2017 году вышла статья «Attention Is All You Need» — и появились **трансформеры**. Их основа — механизм **внимания (attention)**: каждое слово напрямую «смотрит» на все остальные слова и решает, какие из них важны для понимания его смысла.

Для каждого слова считаются три вектора: **запрос** (Q, query), **ключ** (K, key), **значение** (V, value). Тогда:

`Attention(Q, K, V) = softmax(Q · Kᵀ / √d) · V`

- `Q · Kᵀ` — насколько запрос каждого слова совпадает с ключами всех слов;
- softmax превращает это в веса внимания (в сумме 1 по строке);
- результат — взвешенная смесь значений.

Почему трансформеры победили:

- все слова обрабатываются **параллельно**, а не по одному — обучение на видеокартах намного быстрее;
- связь между далёкими словами — один шаг внимания, а не длинная цепочка шагов RNN.

## Языковые модели

**Большие языковые модели (LLM)** — GPT, Claude, YandexGPT, GigaChat — это трансформеры, обученные на огромных корпусах текстов **предсказывать следующий токен** (кусочек слова). Из этой простой задачи на большом масштабе вырастают умения отвечать на вопросы, писать код и переводить. Затем модели дообучают выполнять инструкции и отвечать полезно (в том числе обучением с подкреплением по оценкам людей).

```py
from sentence_transformers import SentenceTransformer

model = SentenceTransformer("cointegrated/rubert-tiny2")      # компактная модель для русского
vectors = model.encode(["доставка опоздала на неделю", "курьер привёз заказ поздно", "не прошла оплата картой"])
```

Чем это полезно аналитику:

- классифицировать тысячи отзывов и обращений по темам и тональности;
- искать похожие тексты и дубликаты через эмбеддинги;
- извлекать структуру из свободного текста (суммы, даты, причины обращений);
- писать и объяснять SQL и код (с обязательной проверкой).

## Шпаргалка

| Понятие | Суть |
|---|---|
| мешок слов | счётчики слов, порядок теряется |
| TF-IDF | частое в документе × редкое в корпусе |
| эмбеддинг | вектор смысла; близость — косинус |
| RNN, LSTM | читают по шагам, хранят скрытое состояние |
| внимание | `softmax(QKᵀ/√d)·V` |
| трансформер | внимание вместо рекурсии, параллельная обработка |
| LLM | трансформер, обученный предсказывать следующий токен |
