## Путь к первой работе

Навыки есть — теперь их нужно показать. Поиск первой работы — отдельный проект: резюме, портфолио, отклики, собеседования. Обычно он занимает 1–3 месяца, поэтому начинай откликаться, не дожидаясь «идеальной готовности».

## Резюме джуниора

Одна страница. Структура:

1. **Заголовок:** «Аналитик данных (Junior)» + контакты + ссылки на GitHub и Telegram/LinkedIn.
2. **О себе** — 2–3 предложения: чем занимаешься и что умеешь.
3. **Навыки** — конкретно: SQL (JOIN, оконные функции, CTE), Python (pandas, matplotlib, scipy), Excel (ВПР, сводные), статистика и A/B-тесты, DataLens/Power BI.
4. **Проекты** — главный раздел для джуниора. Для каждого: задача, методы, **результат с цифрой** и ссылка.
5. **Опыт работы** — любой прошлый опыт; ищи в нём аналитическую часть («вёл учёт…», «считал…»).
6. **Образование и курсы.**

Пример строки про проект:

> **Анализ интернет-магазина** (SQL, pandas, A/B-тест) — нашёл(а), что около 65% новых клиентов не возвращаются в следующем месяце; оценил(а) эффект новой страницы оформления заказа (+1,2 п.п. конверсии, p = 0,014); собрал(а) дашборд в DataLens. [GitHub]

## Портфолио на GitHub

GitHub — «витрина» аналитика. Что нужно:

- аккаунт с понятным именем и фото;
- 1–3 проекта с хорошими README (см. прошлую тему);
- закреплённые (pinned) репозитории на главной странице профиля.

GitHub понадобится и для того, чтобы собрать это приложение в APK.

## Где искать вакансии

- **hh.ru** — основной источник; подпишись на поиск «аналитик данных junior», «младший аналитик», «аналитик-стажёр»;
- **Telegram-каналы** с вакансиями для аналитиков;
- **стажировки** крупных компаний (банки, маркетплейсы, IT) — часто с обучением;
- **LinkedIn** и нетворкинг: сообщества аналитиков, митапы.

Совет: пиши короткое сопроводительное письмо под каждую вакансию — 3–4 предложения, почему ты подходишь, со ссылкой на проект.

## Как проходят собеседования

1. **Скрининг с HR** — мотивация, опыт, ожидания.
2. **Техническое интервью** — SQL-задачи (часто на листочке или в онлайн-редакторе), статистика, вопросы по Python и A/B-тестам.
3. **Тестовое задание** — анализ данных на пару дней с выводами.
4. **Финал** с руководителем — кейсы: «метрика упала на 10%, как будешь искать причину?».

## Частые вопросы на собеседовании

- Чем `WHERE` отличается от `HAVING`?
- Чем `INNER JOIN` отличается от `LEFT JOIN`? Сколько строк получится после соединения?
- Чем `ROW_NUMBER`, `RANK` и `DENSE_RANK` отличаются друг от друга?
- Как найти второй по величине заказ каждого клиента?
- Среднее или медиана — когда что использовать?
- Что такое p-value? Ошибки I и II рода?
- Как рассчитать длительность A/B-теста?
- Выручка упала на 10% — как искать причину? (Дерево метрик!)

Все ответы есть в этом курсе. Перед собеседованием перерешай задания, где открывал(а) решение, — их удобно найти во вкладке «Курс».
