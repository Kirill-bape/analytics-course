## Зачем аналитику статистика

Статистика отвечает на два вопроса: **какое значение типичное** и **насколько данные разбросаны**. Без неё легко сделать неверный вывод — например, решить, что «обычный клиент тратит 12 000 ₽», когда большинство тратит вдвое меньше. Эта тема — про «типичное значение».

## Среднее

**Среднее арифметическое** — сумма всех значений, делённая на их количество. В SQL — `AVG`, в Excel — `СРЗНАЧ`.

Среднее очень чувствительно к **выбросам** — редким огромным значениям. Классический пример: пять сотрудников получают 50, 55, 60, 65 и 400 тысяч (последний — директор). Среднее — 126 тысяч, хотя четверо из пяти получают 65 и меньше.

## Медиана

**Медиана** — значение ровно посередине, если выстроить все значения по порядку. Половина значений меньше медианы, половина — больше.

- 50, 55, **60**, 65, 400 → медиана 60 (среднее — 126);
- если значений чётное количество, медиана — среднее двух центральных: 10, **20, 30**, 40 → 25.

Медиана **устойчива к выбросам**: директору можно поднять зарплату хоть до миллиона — медиана не сдвинется.

```sql
SELECT ROUND(AVG(amount), 2) AS mean_amount,
       median(amount)        AS median_amount
FROM orders
WHERE status = 'delivered';
```

Среднее заметно больше медианы — значит, есть небольшое количество очень крупных заказов (ноутбуки, смартфоны), которые «тянут» среднее вверх.

> 💡 В DuckDB медиана считается функцией `median(x)`. В PostgreSQL пишут `percentile_cont(0.5) WITHIN GROUP (ORDER BY x)`. В Excel — `=МЕДИАНА(...)`.

## Мода

**Мода** — самое частое значение. Полезна для категорий и небольших целых чисел: самый популярный город, самое частое число товаров в заказе.

```sql
SELECT mode(payment_method) AS popular_payment,
       mode(city)           AS popular_city
FROM orders o
JOIN customers c USING (customer_id);
```

## Что выбрать

| Ситуация | Что показывать |
|---|---|
| данные симметричные, без выбросов (рост, время реакции) | среднее ≈ медиане, любое |
| деньги, чеки, зарплаты, время на сайте — есть «хвост» крупных значений | **медиана** (и среднее рядом) |
| категории (город, способ оплаты) | мода |
| нужно посчитать итог (выручку) | среднее: выручка = средний чек × число заказов |

> ⚠️ На собеседованиях любят спрашивать: «средний чек 12 000, медианный 7 000 — что это значит?». Ответ: распределение **скошено вправо** — много обычных заказов и немного очень крупных.

## Шпаргалка

| Мера | SQL (DuckDB) | Excel |
|---|---|---|
| среднее | `AVG(x)` | `СРЗНАЧ` |
| медиана | `median(x)` | `МЕДИАНА` |
| мода | `mode(x)` | `МОДА` |
