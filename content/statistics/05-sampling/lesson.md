## Генеральная совокупность и выборка

Мы почти никогда не видим **все** данные. Опросили 1 000 клиентов из миллиона. Посмотрели заказы за июнь, а хотим сказать что-то о «среднем чеке вообще». Все объекты, о которых мы хотим сделать вывод, — **генеральная совокупность**. Та часть, которую мы реально измерили, — **выборка**.

Чтобы выборка честно представляла совокупность, она должна быть **случайной**: каждый объект мог попасть в неё с одинаковой вероятностью. Опрос только самых активных клиентов или только жителей Москвы даст **смещённый** результат.

## Выборка «шумит»

Возьми две случайные выборки по 100 заказов — средние чеки получатся разными. Это **ошибка выборки**: результат колеблется просто из-за случая. Хорошая новость: чем больше выборка, тем меньше колебания (**закон больших чисел**).

## Стандартная ошибка среднего

Насколько сильно «шумит» среднее выборки, показывает **стандартная ошибка** (SE):

```text
SE = σ / √n
```

- σ — стандартное отклонение данных;
- n — размер выборки.

Чтобы уменьшить ошибку **вдвое**, выборку нужно увеличить **вчетверо** (из-за корня).

## Доверительный интервал

Вместо одного числа честнее назвать **интервал**, в котором, скорее всего, лежит настоящее значение. **95%-й доверительный интервал** для среднего:

```text
среднее ± 1,96 × SE
```

Число 1,96 пришло из правила «95% значений лежат в пределах ±2σ» (точнее — ±1,96σ) нормального распределения.

```sql
SELECT COUNT(*) AS n,
       ROUND(AVG(amount), 0) AS mean,
       ROUND(stddev_samp(amount) / sqrt(COUNT(*)), 0) AS se,
       ROUND(AVG(amount) - 1.96 * stddev_samp(amount) / sqrt(COUNT(*)), 0) AS ci_low,
       ROUND(AVG(amount) + 1.96 * stddev_samp(amount) / sqrt(COUNT(*)), 0) AS ci_high
FROM orders
WHERE status = 'delivered' AND order_date >= '2026-06-01';
```

Как говорить об этом в отчёте: «Средний чек в июне — 14 000 ₽ (95% ДИ: 12 550–15 440 ₽)». Интервал широкий, потому что заказов в выборке меньше тысячи, а чеки сильно разбросаны.

## Доверительный интервал для доли

Для долей (конверсия, доля отмен, доля заказов с промокодом) формула похожая:

```text
SE = √( p × (1 − p) / n )
доля ± 1,96 × SE
```

где p — доля в выборке (например, 0,12), n — размер выборки.

```sql
WITH s AS (
    SELECT AVG(CASE WHEN promo_code IS NOT NULL THEN 1.0 ELSE 0 END) AS p,
           COUNT(*) AS n
    FROM orders
    WHERE order_date >= '2026-06-01'
)
SELECT ROUND(100 * p, 1) AS p_pct,
       ROUND(100 * (p - 1.96 * sqrt(p * (1 - p) / n)), 1) AS low_pct,
       ROUND(100 * (p + 1.96 * sqrt(p * (1 - p) / n)), 1) AS high_pct
FROM s;
```

> 💡 Если интервалы двух групп сильно пересекаются, делать вывод «одна группа лучше другой» рано. Правильная проверка — статистический тест, он будет в модуле A/B-тестов.

## Шпаргалка

| Что | Формула |
|---|---|
| стандартная ошибка среднего | `σ / √n` |
| 95% ДИ для среднего | `среднее ± 1,96 × σ / √n` |
| стандартная ошибка доли | `√(p(1−p)/n)` |
| 95% ДИ для доли | `p ± 1,96 × √(p(1−p)/n)` |
