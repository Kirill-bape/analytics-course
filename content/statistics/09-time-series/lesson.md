## Данные, у которых важен порядок

**Временной ряд** — значения, измеренные через равные промежутки времени: выручка по дням, заказы по неделям, выпуск по сменам. Почти все бизнес-метрики — временные ряды. Главное отличие от обычных данных: соседние значения связаны. Вчерашняя выручка многое говорит о сегодняшней, а строки нельзя перемешивать.

Типичные вопросы к ряду:

- растём или падаем — и насколько быстро;
- это сезонный провал или настоящая проблема;
- что будет в следующем месяце.

## Из чего состоит ряд

Любой ряд удобно разложить на части:

| Часть | Что это | Пример |
|---|---|---|
| **тренд** | долгое движение вверх или вниз | магазин растёт на 3% в месяц |
| **сезонность** | повторяющийся рисунок | по выходным заказов больше; в декабре пик |
| **события** | разовые всплески | распродажа «Чёрная пятница», сбой сайта |
| **шум** | случайные колебания | в один вторник 31 заказ, в другой — 26 |

Хороший анализ ряда начинается с графика. На глаз сразу видно, есть ли тренд и сезонность.

## Агрегация по периодам

Сырые события сначала собирают в ряд с нужным шагом. В SQL — `date_trunc`:

```sql
SELECT CAST(date_trunc('week', order_date) AS DATE) AS week,
       COUNT(*) AS orders,
       SUM(amount) FILTER (WHERE status = 'delivered') AS revenue
FROM orders
GROUP BY week
ORDER BY week
LIMIT 8;
```

> ⚠️ Если в какой-то день не было ни одного заказа, этой даты просто не будет в результате, и ряд «схлопнется». Для честного ряда даты берут из календаря (`generate_series`) и присоединяют к ним данные через `LEFT JOIN`, заменяя пропуски нулём.

## Рост: к прошлому периоду и к прошлому году

- **MoM** (month over month) — рост к прошлому месяцу. Чувствителен к сезонности: декабрь почти всегда лучше ноября, и это не заслуга команды.
- **YoY** (year over year) — рост к тому же месяцу прошлого года. Сезонность сокращается, ведь сравниваем декабрь с декабрём. Поэтому в отчётах для руководства чаще смотрят YoY.

```sql
WITH m AS (
    SELECT CAST(date_trunc('month', order_date) AS DATE) AS month,
           SUM(amount) AS revenue
    FROM orders
    WHERE status = 'delivered'
    GROUP BY month
)
SELECT month, revenue,
       ROUND(100.0 * (revenue / LAG(revenue, 1)  OVER (ORDER BY month) - 1), 1) AS mom_pct,
       ROUND(100.0 * (revenue / LAG(revenue, 12) OVER (ORDER BY month) - 1), 1) AS yoy_pct
FROM m
ORDER BY month DESC
LIMIT 6;
```

`LAG(revenue, 12)` берёт значение на 12 строк выше, то есть год назад. Это работает, только если в ряду нет пропущенных месяцев.

## Сглаживание: скользящее среднее

Дневные данные шумят, и тренд за ними не виден. **Скользящее среднее за 7 дней** убирает и шум, и недельную сезонность: в каждое окно попадает ровно по одному понедельнику, вторнику и так далее.

```sql
WITH d AS (
    SELECT order_date AS day, SUM(amount) AS revenue
    FROM orders
    WHERE status = 'delivered'
    GROUP BY day
)
SELECT day, revenue,
       ROUND(AVG(revenue) OVER (ORDER BY day ROWS BETWEEN 6 PRECEDING AND CURRENT ROW)) AS ma7
FROM d
ORDER BY day DESC
LIMIT 10;
```

То же в pandas:

```python
daily = (orders[orders["status"] == "delivered"]
         .groupby("order_date")["amount"].sum())
ma7 = daily.rolling(7).mean()
print(ma7.tail(5).round(0))
```

## Сезонность по дням недели

Чтобы увидеть недельный рисунок, считают среднее значение для каждого дня недели. Важно усреднять **дневные итоги**, а не отдельные заказы:

```sql
WITH d AS (
    SELECT order_date, COUNT(*) AS orders
    FROM orders
    GROUP BY order_date
)
SELECT isodow(order_date) AS weekday,
       ROUND(AVG(orders), 1) AS avg_orders
FROM d
GROUP BY weekday
ORDER BY weekday;
```

`isodow` возвращает номер дня недели: 1 — понедельник, 7 — воскресенье.

## Прогноз: начинай с простого

Прежде чем строить сложную модель, посчитай **базовые прогнозы**. Сложная модель имеет смысл, только если она их обгоняет.

| Метод | Прогноз на завтра | Когда хорош |
|---|---|---|
| наивный | = сегодня | ряд без сезонности |
| сезонный наивный | = тот же день прошлой недели | есть недельная сезонность |
| среднее | = среднее за последние N дней | ряд стабилен |
| тренд | продолжение прямой | ровный рост или падение |

Дальше идут модели, которые учитывают тренд и сезонность одновременно: экспоненциальное сглаживание (ETS, метод Хольта — Винтерса), ARIMA, Prophet. В Excel похожее делает кнопка «Лист прогноза».

## Как измерить качество прогноза

Прогноз проверяют на данных, которых модель не видела. Для рядов это всегда **последний отрезок времени**: модель строят на данных до 31 мая, а проверяют на июне. Перемешивать строки случайно нельзя. Модель «подсмотрит будущее» и покажет нереально хорошую точность.

Метрики ошибки:

- **MAE** — средняя абсолютная ошибка: `среднее(|факт − прогноз|)`. Понятна в рублях и штуках.
- **MAPE** — средняя абсолютная ошибка в процентах: `среднее(|факт − прогноз| / факт) × 100%`. Удобна для сравнения рядов разного масштаба. Но взрывается, когда факт близок к нулю.

```python
import numpy as np

fact = np.array([200, 250, 400])
forecast = np.array([180, 260, 300])
mae = np.mean(np.abs(fact - forecast))
mape = np.mean(np.abs(fact - forecast) / fact) * 100
print("MAE:", round(mae, 1), " MAPE:", round(mape, 1), "%")
```

## Частые ошибки

- Сравнивать месяц с прошлым месяцем и не учитывать сезонность.
- Делать выводы по одному дню: дневной ряд шумный.
- Забыть, что в месяцах разное число дней. Февраль «проигрывает» марту на 10% просто потому, что он короче. Помогает выручка **в день**.
- Не замечать неполный последний период: 15 дней текущего месяца сравнивают с полным прошлым месяцем — и «падение» на 50%.

## Шпаргалка

| Задача | Как |
|---|---|
| ряд по неделям / месяцам | `date_trunc('week', d)`, `date_trunc('month', d)` |
| рост к прошлому периоду | `x / LAG(x) OVER (ORDER BY period) - 1` |
| рост к прошлому году (месяцы) | `LAG(x, 12) OVER (ORDER BY month)` |
| скользящее среднее за 7 | `AVG(x) OVER (ORDER BY day ROWS BETWEEN 6 PRECEDING AND CURRENT ROW)` |
| то же в pandas | `series.rolling(7).mean()` |
| день недели | `isodow(date)` (1 — пн, 7 — вс) |
| ошибка прогноза | MAE = `mean(|факт − прогноз|)`, MAPE = `mean(|факт − прогноз| / факт)` |
