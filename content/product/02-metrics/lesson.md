## Метрики, на которых живёт продукт

Метрики магазина вроде выручки и среднего чека мы уже считали. Продуктовая аналитика добавляет к ним метрики **поведения пользователей**: сколько людей пользуется продуктом, как часто возвращаются, где отваливаются. Разберём главные — и то, как их легко посчитать неправильно.

> 📌 В наших данных нет логов посещений, только заказы. Поэтому «активным» будем считать клиента, сделавшего заказ. В реальном продукте активность обычно определяют по входу в приложение или целевому действию.

## Аудитория: DAU, WAU, MAU

- **DAU** (daily active users) — уникальные активные пользователи за день;
- **WAU** — за неделю, **MAU** — за месяц.

```sql
-- MAU по месяцам: уникальные клиенты с заказом
SELECT CAST(date_trunc('month', order_date) AS DATE) AS month,
       COUNT(DISTINCT customer_id) AS mau
FROM orders
GROUP BY month
ORDER BY month DESC
LIMIT 6;
```

> ⚠️ MAU **нельзя** получить, сложив 30 DAU: один человек, активный 10 дней, посчитается 10 раз. Уникальные считаются для каждого периода отдельно.

**Stickiness** (липкость) = средний DAU / MAU. Показывает, какую долю месяца типичный пользователь активен. Для мессенджера это 50% и выше, для интернет-магазина — несколько процентов: покупают не каждый день.

## Конверсия

**Конверсия** — доля пользователей, сделавших целевое действие, среди тех, кто мог его сделать:

```text
конверсия = сделали действие / все, кто мог
```

Главное — правильный **знаменатель**. «Конверсия в покупку» от всех посетителей сайта, от зашедших в корзину и от начавших оформление — три разные метрики. Всегда пиши, от чего считается доля.

```sql
-- Конверсия в покупку в эксперименте checkout_v2 по устройствам
SELECT device,
       COUNT(*) AS users,
       ROUND(100.0 * AVG(converted), 2) AS conversion_pct
FROM ab_users
WHERE experiment = 'checkout_v2'
GROUP BY device
ORDER BY conversion_pct DESC;
```

## Удержание (retention)

**Удержание** — доля пользователей, которые вернулись через N дней (недель, месяцев) после первого действия. Это главная метрика ценности продукта: если люди не возвращаются, продукт им не нужен, сколько ни привлекай новых.

Два способа считать:

- **классический (N-day) retention** — вернулся **именно** в день N (или в N-й месяц);
- **rolling retention** — вернулся в день N **или позже**. Он всегда выше классического.

Удержание считают по **когортам** — группам пользователей, пришедших в одно время, — подробно в теме про когорты.

**Отток** (churn) — противоположность удержания: доля пользователей, которые перестали пользоваться продуктом за период. Определение «перестал» нужно зафиксировать: например, «нет заказов 90 дней».

## Деньги на пользователя

| Метрика | Формула | Что показывает |
|---|---|---|
| **ARPU** | выручка / все пользователи | сколько в среднем приносит пользователь |
| **ARPPU** | выручка / платящие пользователи | сколько тратит тот, кто платит |
| **доля платящих** | платящие / все пользователи | насколько массово платят |
| **частота** | заказы / покупатели | как часто покупают |
| **средний чек** (AOV) | выручка / заказы | сколько в одном заказе |

Они связаны: ARPU = доля платящих × ARPPU. Поэтому рост ARPU можно получить двумя разными путями: больше людей начали платить или платящие стали тратить больше.

```sql
-- ARPU, ARPPU и доля платящих в эксперименте checkout_v2
SELECT group_name,
       ROUND(AVG(revenue), 1)                                   AS arpu,
       ROUND(SUM(revenue) / NULLIF(SUM(converted), 0), 1)       AS arppu,
       ROUND(100.0 * AVG(converted), 2)                         AS paying_pct
FROM ab_users
WHERE experiment = 'checkout_v2'
GROUP BY group_name
ORDER BY group_name;
```

## Как выбирать метрики

- **North Star** — одна главная метрика, которая отражает ценность для пользователя и бизнеса. Для магазина это, например, «число доставленных заказов в месяц», а не просто трафик.
- Каждая метрика должна быть **действенной**: понятно, что делать, если она меняется.
- Избегай **метрик тщеславия**: «зарегистрировано 1 млн пользователей за всё время» растёт всегда и ничего не говорит о здоровье продукта.
- Записывай **определение**: что считается активностью, по какой дате, кого исключаем.

## Шпаргалка

| Метрика | Как считать |
|---|---|
| DAU / MAU | уникальные пользователи за день / месяц — отдельно для каждого периода |
| stickiness | средний DAU / MAU |
| конверсия | сделали действие / могли сделать (знаменатель пиши явно) |
| retention N | вернулись в период N / пришли в когорте |
| rolling retention | вернулись в период N или позже / пришли |
| churn | перестали быть активными / были активны |
| ARPU | выручка / все пользователи |
| ARPPU | выручка / платящие |
| ARPU | = доля платящих × ARPPU |
