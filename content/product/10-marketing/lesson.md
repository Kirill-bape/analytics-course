## Окупается ли маркетинг

Маркетинг тратит деньги, чтобы привести клиентов. Задача маркетинговой аналитики — ответить: **сколько стоит клиент из каждого канала, сколько он приносит и куда выгоднее направить следующий рубль**.

## Воронка рекламы и её метрики

```text
показы → клики → визиты → заказы → повторные заказы
```

| Метрика | Формула | Что показывает |
|---|---|---|
| **CPM** | стоимость / показы × 1 000 | цена тысячи показов |
| **CTR** | клики / показы | насколько реклама цепляет |
| **CPC** | стоимость / клики | цена клика |
| **CR** | заказы / клики (или визиты) | насколько посадочная страница и продукт конвертируют |
| **CPA** / **CAC** | стоимость / заказы (новые клиенты) | цена целевого действия / нового клиента |
| **ROAS** | выручка / стоимость рекламы | сколько выручки на рубль рекламы |
| **ROMI** | (прибыль − стоимость) / стоимость | окупается ли реклама с учётом маржи |

Метрики связаны: CPA = CPC / CR. Дорогой клик может быть выгодным, если с него хорошо покупают, а дешёвый — убыточным.

> ⚠️ ROAS 300% звучит отлично, но при марже 25% каждый рубль рекламы приносит 3 ₽ выручки и 0,75 ₽ прибыли — то есть убыток. Решения принимают по **ROMI** — с учётом маржи — и по **LTV**, а не по выручке первого заказа.

## CAC и окупаемость по каналам

Расходы по каналам берут из рекламных кабинетов, новых клиентов — из своих данных. Ниже расходы за первое полугодие 2026 года заданы прямо в запросе (в реальности это отдельная таблица):

```sql
WITH spend(channel, cost) AS (
    VALUES ('ads', 2400000), ('social', 1500000), ('bloggers', 900000),
           ('referral', 300000), ('organic', 0)
),
new_clients AS (
    SELECT c.acquisition_channel AS channel, COUNT(*) AS clients
    FROM customers c
    WHERE c.registration_date >= '2026-01-01'
      AND EXISTS (SELECT 1 FROM orders o WHERE o.customer_id = c.customer_id AND o.status = 'delivered')
    GROUP BY c.acquisition_channel
)
SELECT s.channel, s.cost, n.clients,
       ROUND(s.cost / n.clients) AS cac
FROM spend s
JOIN new_clients n ON n.channel = s.channel
ORDER BY cac DESC;
```

Дальше CAC сравнивают с LTV клиентов того же канала (из когортного анализа). Канал с низким CAC может приводить клиентов, которые не возвращаются, — и тогда он хуже, чем кажется.

## Промокоды

Промокоды — частый инструмент маркетинга. Вопросы к ним:

- **сколько заказов и выручки** пришло с каждым кодом;
- **какой ценой**: средняя скидка, доля скидки в выручке;
- **кого привлёк код**: новых клиентов или тех, кто купил бы и так;
- **вернулись ли** клиенты, пришедшие по коду, без скидки.

```sql
SELECT promo_code,
       COUNT(*)                              AS orders,
       ROUND(SUM(amount))                    AS revenue,
       ROUND(SUM(discount))                  AS discount_total,
       ROUND(100.0 * SUM(discount) / SUM(amount + discount), 1) AS discount_pct
FROM orders
WHERE status = 'delivered' AND promo_code IS NOT NULL
GROUP BY promo_code
ORDER BY revenue DESC;
```

## Инкрементальность: что произошло бы без рекламы

Главный вопрос маркетинга — **инкрементальность**: сколько продаж реклама добавила сверх тех, что случились бы и без неё. Атрибуция по кликам на этот вопрос не отвечает: человек, который и так шёл покупать, мог по дороге кликнуть на рекламу.

Способы измерить честно:

- **holdout-группа**: части аудитории рекламу не показывают и сравнивают покупки;
- **гео-эксперимент**: рекламу выключают в части регионов (разность разностей из модуля A/B);
- **пауза канала** на неделю-две и наблюдение за общими продажами.

## Как распределять бюджет

Каналы насыщаются: первые рубли в канале приводят самых заинтересованных людей, а каждый следующий миллион — всё более дорогих клиентов. Поэтому бюджет переносят туда, где **следующий** рубль даёт больше прибыли (по предельному ROMI), а не туда, где был лучший средний результат. Изменения делают постепенно и проверяют эффект.

## Шпаргалка

| Метрика | Формула |
|---|---|
| CTR | клики / показы |
| CPC | стоимость / клики |
| CR | заказы / клики |
| CPA | стоимость / заказы = CPC / CR |
| CAC | расходы канала / новые клиенты канала |
| ROAS | выручка / расходы |
| ROMI | (прибыль − расходы) / расходы |
| окупаемость клиента | сравнить CAC с LTV по прибыли |
| инкрементальность | holdout, гео-эксперимент, пауза канала |
