## NumPy — двигатель под капотом pandas

Каждый столбец DataFrame внутри — это **массив NumPy**. NumPy хранит числа плотно, одним блоком памяти, и считает над ними на скорости языка C. Поэтому `orders["amount"] * 1.2` по миллиону строк выполняется мгновенно, а цикл `for` по тем же строкам — в сотни раз дольше.

Аналитику NumPy нужен в трёх случаях:

- **векторные расчёты** вместо медленных циклов и `apply`;
- **случайные числа и симуляции**: оценить вероятность, построить доверительный интервал бутстрапом, проверить, как поведёт себя тест;
- **математика** для статистики и машинного обучения.

А **SciPy** — надстройка с готовыми статистическими распределениями и тестами (мы уже пользовались `scipy.stats`), оптимизацией и интерполяцией.

## Массивы и векторные операции

```python
import numpy as np

qty = np.array([2, 1, 3, 1])
price = np.array([4990, 59890, 790, 3690])

print(qty * price)            # поэлементно: [9980 59890 2370 3690]
print((qty * price).sum())    # выручка
print(price.mean(), price.max(), np.median(price))
```

Операции над массивами работают **поэлементно**: никаких циклов. Если один из операндов — число, оно применяется к каждому элементу. Это называется **broadcasting** (растягивание): `price * 0.9` умножит каждую цену.

| Код | Что делает |
|---|---|
| `np.array([…])` | массив из списка |
| `arr.sum()`, `arr.mean()`, `arr.std()` | итоги |
| `np.median(arr)`, `np.percentile(arr, 90)` | медиана, 90-й процентиль |
| `arr.round(2)` | округление |
| `np.log(arr)`, `np.sqrt(arr)` | функции к каждому элементу |
| `orders["amount"].to_numpy()` | столбец pandas → массив |

## Маски и np.where

Сравнение массива даёт массив `True`/`False` — **маску**. Её можно использовать для отбора и подсчёта (`True` считается как 1):

```python
amounts = orders["amount"].to_numpy()
big = amounts >= 10000
print("доля крупных:", round(big.mean(), 3))
print("их выручка:", amounts[big].sum())
```

`np.where(условие, если_да, если_нет)` — это векторный `ЕСЛИ`. Он работает в десятки раз быстрее, чем `apply` с функцией:

```python
orders["size"] = np.where(orders["amount"] >= 10000, "крупный", "обычный")
print(orders["size"].value_counts())
```

Для нескольких условий есть `np.select([усл1, усл2], [знач1, знач2], default=…)`. Условия проверяются по порядку, как в `ЕСЛИМН`.

## Случайные числа и воспроизводимость

```python
rng = np.random.default_rng(42)       # генератор с «зерном» 42
print(rng.integers(1, 7, size=10))    # 10 бросков кубика
print(rng.normal(100, 15, size=3).round(1))   # нормальное распределение
print(rng.choice(["A", "B"], size=6))         # случайный выбор
```

**Зерно** (`seed`) делает случайность воспроизводимой: с тем же зерном получаются те же числа. В отчёте, построенном на симуляции, всегда фиксируй зерно, иначе коллега получит другие цифры.

## Симуляция: когда формулу лень искать

Иногда проще смоделировать процесс, чем выводить формулу. Пример: какова вероятность, что сумма двух кубиков равна 7?

```python
rng = np.random.default_rng(0)
n = 100_000
dice = rng.integers(1, 7, size=(n, 2))      # n строк по два броска
p = (dice.sum(axis=1) == 7).mean()
print(round(p, 3))     # точный ответ — 1/6 ≈ 0,167
```

`axis=1` — считать по строкам (сумма двух кубиков в каждом опыте). `axis=0` — по столбцам.

## Бутстрап: доверительный интервал для чего угодно

Для среднего есть формула доверительного интервала. А для медианы? Для 90-го процентиля? Здесь выручает **бутстрап**: тысячи раз берём из данных случайную выборку **с возвращением** того же размера, считаем нужную статистику и смотрим на разброс результатов.

```python
rng = np.random.default_rng(1)
x = orders.loc[orders["status"] == "delivered", "amount"].to_numpy()

medians = [np.median(rng.choice(x, size=len(x), replace=True)) for _ in range(1000)]
low, high = np.percentile(medians, [2.5, 97.5])
print("медиана:", np.median(x), " 95% ДИ:", round(low), "–", round(high))
```

Бутстрап широко используют в A/B-тестах для метрик со сложным распределением. Подробнее о нём — в модуле A/B-тестов.

## SciPy: распределения и тесты

`scipy.stats` знает все популярные распределения. У каждого одинаковые методы:

| Метод | Что даёт | Пример для нормального |
|---|---|---|
| `pdf` / `pmf` | плотность / вероятность точки | `stats.norm.pdf(0)` |
| `cdf` | вероятность «не больше x» | `stats.norm.cdf(1.96)` ≈ 0,975 |
| `sf` | вероятность «больше x» = 1 − cdf | `stats.norm.sf(2)` ≈ 0,023 |
| `ppf` | обратная к cdf: какой x даёт вероятность | `stats.norm.ppf(0.975)` ≈ 1,96 |
| `rvs` | случайные числа | `stats.norm.rvs(size=5)` |

```python
from scipy import stats

# Средний чек 12 000, стандартное отклонение 4 000, распределение нормальное.
# Какая доля чеков больше 20 000?
print(round(stats.norm.sf(20000, loc=12000, scale=4000), 4))
```

`loc` — среднее, `scale` — стандартное отклонение. Тесты из той же библиотеки (`ttest_ind`, `chi2_contingency`, `mannwhitneyu`) мы разбирали в теме про статистические тесты.

## Шпаргалка

| Задача | Код |
|---|---|
| поэлементный расчёт | `qty * price` |
| условие для массива | `np.where(cond, a, b)`, `np.select([...], [...], default)` |
| доля по маске | `(arr >= 10000).mean()` |
| процентиль | `np.percentile(arr, 90)` |
| генератор случайных чисел | `rng = np.random.default_rng(42)` |
| выборка с возвращением | `rng.choice(x, size=len(x), replace=True)` |
| по строкам / по столбцам | `axis=1` / `axis=0` |
| хвост нормального | `stats.norm.sf(x, loc=μ, scale=σ)` |
| квантиль нормального | `stats.norm.ppf(0.975)` |
