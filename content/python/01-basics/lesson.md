## Зачем аналитику Python

SQL отлично достаёт и считает данные. Python нужен, когда задача сложнее: объединить данные из разных источников, почистить «грязную» выгрузку, провести статистический тест, построить график, автоматизировать ежедневный отчёт. Главная библиотека аналитика в Python — **pandas**. Но сначала — несколько основ языка, без которых pandas не понять.

Код здесь выполняется прямо в браузере. Первый запуск занимает 10–30 секунд: загружается Python с библиотеками. Дальше всё быстро.

## Переменные

**Переменная** — имя, под которым хранится значение. Знак `=` означает «запомни»:

```python
price = 2290
quantity = 3
revenue = price * quantity
revenue
```

Последняя строка кода показывается как результат (как в Jupyter Notebook — главном инструменте аналитиков). Чтобы вывести несколько значений, используют `print`:

```python
price = 2290
quantity = 3
print(price * quantity)
print("Готово")
```

## Типы данных

| Тип | Пример | Что это |
|---|---|---|
| `int` | `42`, `-7` | целое число |
| `float` | `3.14`, `0.9` | дробное число — **через точку** |
| `str` | `"Москва"`, `'Казань'` | строка (текст), в кавычках |
| `bool` | `True`, `False` | логическое значение |

Арифметика: `+ - * /`, возведение в степень `**`, целочисленное деление `//`, остаток `%`. Функция `round(x, 2)` округляет.

```python
avg_check = 11779.7123
print(round(avg_check, 2))
print(type(avg_check))
```

## f-строки: текст со значениями

Чтобы вставить значение в текст, перед кавычками ставят `f`, а значение — в фигурные скобки:

```python
city = "Москва"
revenue = 40160676.35
print(f"Выручка в городе {city}: {revenue:,.0f} ₽")
```

`:,.0f` внутри скобок — формат: разделитель тысяч и 0 знаков после запятой.

## Списки

**Список** — упорядоченный набор значений в квадратных скобках:

```python
prices = [2290, 4790, 459, 12990, 890]
print(len(prices))        # количество элементов
print(sum(prices))        # сумма
print(max(prices), min(prices))
print(prices[0])          # первый элемент — нумерация с нуля!
print(sorted(prices))     # отсортированная копия
```

## Словари

**Словарь** хранит пары «ключ → значение» — как маленькая таблица-справочник:

```python
city_orders = {"Москва": 4120, "Казань": 730, "Самара": 450}
print(city_orders["Казань"])
city_orders["Уфа"] = 440      # добавить новую пару
city_orders
```

> 💡 Каждый пример и каждое задание выполняются **отдельно**: переменные из одного примера не видны в другом. Если нужна переменная — определи её в том же окне кода.

## Как сдавать задания

В заданиях обычно нужно положить ответ в переменную **`result`** — её проверяет приложение. Иногда нужно именно **вывести** текст через `print` — тогда об этом сказано в задании.

## Шпаргалка

| Задача | Код |
|---|---|
| переменная | `x = 10` |
| вывести | `print(x)` |
| текст со значением | `f"Итого: {x}"` |
| список | `[1, 2, 3]`, `len()`, `sum()`, `max()` |
| словарь | `{"ключ": значение}`, `d["ключ"]` |
| округлить | `round(x, 2)` |
