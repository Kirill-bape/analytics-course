## Очистка данных в pandas

В модуле Excel мы чистили данные формулами. В pandas то же самое делается для всего столбца одной строкой — и так же легко повторяется на завтрашней выгрузке.

## Пропуски (NaN)

Пустые значения в pandas выглядят как `NaN` (или `None`, `NaT` для дат).

```python
customers.isna().sum()
```

`isna()` превращает таблицу в `True`/`False`, а `sum()` считает `True` в каждом столбце — получаем число пропусков по столбцам.

Что делать с пропусками:

| Способ | Код | Когда |
|---|---|---|
| удалить строки | `df.dropna(subset=["city"])` | пропусков мало, и без значения строка бесполезна |
| заполнить константой | `df["promo_code"].fillna("без промокода")` | у пустоты есть смысл |
| заполнить медианой | `df["rating"].fillna(df["rating"].median())` | числа, нужна оценка |
| оставить | — | функции `mean`, `sum` сами пропускают `NaN` |

## Текстовые столбцы: .str

У текстовых столбцов есть аксессор `.str` с методами, похожими на функции Excel:

| Задача | pandas | Excel |
|---|---|---|
| убрать пробелы по краям | `.str.strip()` | `СЖПРОБЕЛЫ` |
| регистр | `.str.lower()`, `.str.upper()`, `.str.title()` | `СТРОЧН`, `ПРОПИСН`, `ПРОПНАЧ` |
| заменить | `.str.replace("₽", "")` | `ПОДСТАВИТЬ` |
| содержит | `.str.contains("набор")` | `ПОИСК` |

```python
messy = pd.Series(["  москва", "МОСКВА ", "Казань", "санкт-петербург"])
messy.str.strip().str.title()
```

## Типы данных

Если число прочиталось как текст (`"12 990 ₽"`), его чистят и превращают в число через `astype`:

```python
prices = pd.Series(["12 990 ₽", "1 290,50 ₽", "459 ₽"])
(
    prices.str.replace(" ", "")
          .str.replace("₽", "")
          .str.replace(",", ".")
          .astype(float)
)
```

Даты из текста — `pd.to_datetime(df["date"], format="%d.%m.%Y")`.

## Дубликаты

```text
df.duplicated().sum()                      # сколько полных дублей
df.drop_duplicates()                       # убрать полные дубли
df.drop_duplicates(subset=["order_id"])    # дубли по ключу
```

```python
print(orders.duplicated().sum())                               # полных дублей в заказах нет
print(orders.drop_duplicates(subset=["customer_id"]).shape)    # по одной строке на клиента
```

## Шпаргалка

| Задача | Код |
|---|---|
| пропуски по столбцам | `df.isna().sum()` |
| заполнить пропуски | `df["x"].fillna(значение)` |
| удалить строки с пропусками | `df.dropna(subset=["x"])` |
| почистить текст | `df["x"].str.strip().str.title()` |
| текст → число | `.str.replace(...).astype(float)` |
| убрать дубли | `df.drop_duplicates()` |
