## Зачем снова про функции

В теме про условия и циклы мы написали первые функции. Теперь научимся делать их удобными: с параметрами по умолчанию, несколькими результатами и понятным описанием. А ещё разберёмся, что такое классы и модули. Ты пользуешься ими с первого урока: `pd.DataFrame` — это класс, `import pandas` — это модуль.

Правило, которое экономит часы: **если один и тот же кусок кода скопирован третий раз — пора сделать функцию.** Исправлять ошибку придётся в одном месте, а не в трёх.

## Параметры по умолчанию и именованные аргументы

```python
def price_with_discount(price, pct=10):
    """Цена после скидки pct процентов, с округлением до копеек."""
    return round(price * (1 - pct / 100), 2)

print(price_with_discount(4990))          # скидка по умолчанию — 10%
print(price_with_discount(4990, 25))      # своя скидка
print(price_with_discount(pct=5, price=4990))  # именованные аргументы — порядок не важен
```

- `pct=10` — значение **по умолчанию**: если аргумент не передали, берётся оно.
- Строка в тройных кавычках сразу под `def` — **docstring**, описание функции. Его показывает `help(price_with_discount)` и подсказки в редакторе.
- Аргументы можно передавать по имени: так вызов читается без заглядывания в определение функции.

> ⚠️ Не делай значением по умолчанию список или словарь (`def f(items=[])`). Такой список создаётся один раз и копит значения между вызовами. Пиши `items=None`, а внутри: `if items is None: items = []`.

## Несколько результатов

Функция может вернуть сразу несколько значений через запятую. На самом деле это кортеж, его удобно «распаковать» в переменные:

```python
def amount_stats(amounts):
    return min(amounts), max(amounts), sum(amounts) / len(amounts)

low, high, avg = amount_stats([1200, 15400, 3300, 890])
print(low, high, round(avg, 1))
```

## return и print — не одно и то же

`print` только **показывает** значение на экране. `return` **отдаёт** его наружу, и результат можно сохранить в переменную и использовать дальше. Функция без `return` возвращает `None`. Частая ошибка новичка: функция печатает правильное число, а `result = f(...)` оказывается пустым.

## Область видимости

Переменные, созданные внутри функции, живут только внутри неё. Функция видит переменные снаружи, но менять их без особых приёмов не может. Хорошая привычка — передавать всё, что нужно функции, через параметры, а не брать из «внешнего мира». Тогда функцию легко проверить и переиспользовать.

## lambda и apply

`lambda` — короткая безымянная функция в одну строку. Её удобно передавать туда, где ждут функцию: в `apply`, `sorted`, `map`.

```python
segment = lambda a: "крупный" if a >= 10000 else "обычный"
print(orders["amount"].apply(segment).value_counts())
```

`apply` применяет функцию к каждому значению столбца. С `axis=1` — к каждой **строке** таблицы, тогда внутри доступны все её столбцы:

```python
def delivery_label(row):
    if row["status"] != "delivered":
        return "не доставлен"
    days = (row["delivery_date"] - row["order_date"]).days
    return "быстро" if days <= 3 else "долго"

sample = orders.head(1000)
print(sample.apply(delivery_label, axis=1).value_counts())
```

> 💡 `apply` с `axis=1` медленный: Python обрабатывает строки по одной. На миллионах строк выбирай **векторные** операции: `np.where`, `.map`, арифметику столбцов. Их разберём в теме про NumPy и pandas для профи.

## Классы: свои типы данных

**Класс** — шаблон, по которому создаются объекты. Объект хранит данные (**атрибуты**) и умеет действия (**методы**). `DataFrame` — класс: у каждой таблицы свои данные и общие методы `groupby`, `merge`, `head`.

Свой класс аналитику нужен редко, но читать чужие классы и понимать, что происходит, нужно постоянно. Минимальный пример:

```python
class Report:
    def __init__(self, title, data):
        self.title = title      # атрибуты конкретного отчёта
        self.data = data

    def total(self):            # метод — функция внутри класса
        return self.data["amount"].sum()

    def summary(self):
        return f"{self.title}: {len(self.data)} заказов на {self.total():.0f} ₽"

june = Report("Июнь 2026", orders[orders["order_date"] >= "2026-06-01"])
print(june.summary())
```

- `__init__` вызывается при создании объекта: `Report("Июнь 2026", …)`.
- `self` — ссылка на сам объект. Через неё методы достают атрибуты: `self.data`.
- Каждый объект хранит свои данные: можно создать отчёт за май, и он не смешается с июньским.

## Модули и библиотеки

**Модуль** — файл с кодом, который можно подключить через `import`. Python поставляется с большой стандартной библиотекой, и многое уже написано за нас:

```python
import math
from collections import Counter
from datetime import date, timedelta

print(math.sqrt(900))
print(Counter(["Москва", "Казань", "Москва"]).most_common(1))
print(date(2026, 6, 30) + timedelta(days=7))
```

| Запись | Что делает |
|---|---|
| `import math` | подключить модуль, обращаться через `math.sqrt` |
| `import pandas as pd` | подключить под коротким именем |
| `from collections import Counter` | взять из модуля одно имя |

Свои функции, которые нужны в разных ноутбуках, кладут в отдельный файл, например `helpers.py`, и подключают: `from helpers import price_with_discount`. Сторонние библиотеки (pandas, requests, scikit-learn) ставят командой `pip install имя` — подробнее в теме про инструменты.

## Шпаргалка

| Задача | Как |
|---|---|
| значение по умолчанию | `def f(price, pct=10):` |
| описание функции | `"""Что делает функция."""` первой строкой |
| несколько результатов | `return a, b` → `x, y = f()` |
| короткая функция | `lambda x: x * 2` |
| функция к столбцу | `df["col"].apply(f)` |
| функция к строке | `df.apply(f, axis=1)` |
| класс | `class Name:` + `def __init__(self, …):` |
| подключить модуль | `import math`, `from collections import Counter` |
