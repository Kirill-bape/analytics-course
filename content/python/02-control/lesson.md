## Условия: if / elif / else

Программа может выбирать, что делать, в зависимости от условия. Это то же самое, что `CASE WHEN` в SQL и `ЕСЛИ` в Excel.

```python
amount = 12500

if amount >= 10000:
    size = "крупный"
elif amount >= 3000:
    size = "средний"
else:
    size = "маленький"

size
```

Правила записи:

- после условия ставится **двоеточие** `:`;
- строки, которые выполняются при условии, сдвигаются **отступом в 4 пробела** — в Python отступы обязательны, по ним язык понимает, где заканчивается блок;
- сравнение — `==` (два знака), «не равно» — `!=`; одно `=` — это присваивание;
- условия объединяют словами `and`, `or`, `not`.

## Цикл for

`for` повторяет действие для каждого элемента списка:

```python
prices = [2290, 4790, 459, 12990]

for p in prices:
    print(p, "₽ →", round(p * 0.85), "₽ со скидкой")
```

Частый приём — **накопление**: заводим переменную-счётчик и обновляем её в цикле.

```python
amounts = [1200, 15400, 3300, 890, 22000, 7600]

big = 0
for a in amounts:
    if a >= 10000:
        big = big + 1      # можно короче: big += 1

big
```

`range(n)` даёт числа от 0 до n−1 — удобно, когда нужно повторить что-то n раз.

## Функции

**Функция** — именованный кусок кода, который можно вызывать много раз. Её объявляют словом `def`, а результат возвращают через `return`:

```python
def margin_pct(price, cost):
    """Маржинальность в процентах."""
    return round((price - cost) / price * 100, 1)

print(margin_pct(2290, 1500))
print(margin_pct(84990, 70000))
```

Функции — это то, что делает код аккуратным: логика расчёта описана в одном месте, а вызывается где угодно.

## Генераторы списков

Короткий способ получить новый список из старого — **list comprehension**:

```python
prices = [2290, 4790, 459, 12990]

with_discount = [round(p * 0.85) for p in prices]
expensive = [p for p in prices if p > 3000]

print(with_discount)
print(expensive)
```

Читается как по-русски: «`round(p * 0.85)` для каждого `p` из `prices`», «`p` для каждого `p` из `prices`, если `p > 3000`».

> 💡 В pandas циклы почти не пишут: операции применяются сразу ко всему столбцу. Но понимать циклы и условия нужно, чтобы читать чужой код и писать свои функции.

## Шпаргалка

| Задача | Код |
|---|---|
| условие | `if x > 0:` / `elif …:` / `else:` |
| цикл по списку | `for x in items:` |
| счётчик | `count += 1` |
| функция | `def name(a, b):` … `return …` |
| новый список | `[f(x) for x in items if условие]` |
