## Разница есть — но не случайна ли она?

Даже если две группы видят **одинаковую** страницу (так называемый A/A-тест), их конверсии не совпадут до сотых: 10,1% против 9,8%. Это шум — как при подбрасывании монеты 100 раз орёл выпадает не ровно 50 раз. Поэтому вопрос не «есть ли разница», а «**слишком ли она большая, чтобы быть случайной?**»

## p-value

**p-value** — вероятность получить такую же или ещё большую разницу, **если на самом деле разницы нет** (если верна H₀).

- p-value = 0,30 → такая разница часто возникает случайно; повода верить в эффект нет;
- p-value = 0,01 → при отсутствии эффекта такое бывает лишь в 1% случаев; скорее всего, эффект реальный.

Заранее выбирают **уровень значимости α** (альфа), обычно **0,05**. Правило:

- **p < α** — результат **статистически значимый**, отвергаем H₀;
- **p ≥ α** — данных недостаточно, чтобы утверждать, что эффект есть.

> ⚠️ p-value — **не** вероятность того, что гипотеза верна, и не «размер эффекта». Большая выборка может сделать значимым даже крошечный, бесполезный для бизнеса эффект.

## Два вида ошибок

| | На самом деле эффекта нет | На самом деле эффект есть |
|---|---|---|
| **Тест говорит «эффект есть»** | ошибка I рода (ложная тревога), вероятность = α | верно |
| **Тест говорит «эффекта нет»** | верно | ошибка II рода (пропуск), вероятность = β |

**Мощность** теста = 1 − β — вероятность заметить эффект, если он есть. Обычно хотят мощность 80%.

## z-тест для конверсий

Для сравнения двух долей (конверсий) используют **z-тест**:

```text
p = (купившие_A + купившие_B) / (n_A + n_B)          — общая конверсия
SE = √( p × (1 − p) × (1/n_A + 1/n_B) )               — стандартная ошибка разницы
z = (конверсия_B − конверсия_A) / SE
```

Чем больше |z|, тем меньше p-value. Граница значимости при α = 0,05 — |z| > 1,96 (знакомое число из доверительных интервалов).

В Python p-value по z считает `scipy`:

```python
from scipy import stats

t = ab_users[ab_users["experiment"] == "checkout_v2"]
g = t.groupby("group_name")["converted"].agg(["sum", "count"])
buyers_a, n_a = g.loc["A"]
buyers_b, n_b = g.loc["B"]

p_a, p_b = buyers_a / n_a, buyers_b / n_b
p_pool = (buyers_a + buyers_b) / (n_a + n_b)
se = (p_pool * (1 - p_pool) * (1 / n_a + 1 / n_b)) ** 0.5
z = (p_b - p_a) / se
p_value = 2 * (1 - stats.norm.cdf(abs(z)))   # двусторонний тест

print(f"A: {p_a:.2%}, B: {p_b:.2%}, z = {z:.2f}, p-value = {p_value:.4f}")
```

`stats.norm.cdf` — функция нормального распределения. Умножаем на 2, потому что тест **двусторонний**: нас интересует отличие в любую сторону.

## Шпаргалка

| Понятие | Смысл |
|---|---|
| p-value | вероятность такой разницы при отсутствии эффекта |
| α = 0,05 | порог; p < α — значимо |
| ошибка I рода | увидеть эффект, которого нет |
| ошибка II рода | не заметить эффект, который есть |
| мощность | 1 − β, обычно 80% |
| граница z | \|z\| > 1,96 при α = 0,05 |
