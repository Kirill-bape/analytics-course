## Полный разбор эксперимента

Разберём эксперимент `checkout_v2` так, как это делают в реальной работе: проверка данных → главная метрика → дополнительные метрики → вывод.

## 1. Проверка данных

Размеры групп и состав — уже знакомый шаг (SRM). Группы по 8 000 человек, доли устройств похожие — можно продолжать.

## 2. Конверсия: хи-квадрат

Для конверсий кроме z-теста используют **критерий хи-квадрат** — он работает с таблицей «группа × купил/не купил». Для двух групп его p-value совпадает с z-тестом (если отключить поправку `correction=False`).

```python
from scipy import stats

t = ab_users[ab_users["experiment"] == "checkout_v2"]
table = pd.crosstab(t["group_name"], t["converted"])
chi2, p_value, dof, expected = stats.chi2_contingency(table, correction=False)
print(table)
print(f"p-value = {p_value:.4f}")
```

`pd.crosstab` строит таблицу сопряжённости — сколько пользователей в каждой комбинации группы и результата.

## 3. Выручка на пользователя: t-тест

**ARPU** (выручка на пользователя) — среднее, а не доля. Средние двух групп сравнивают **t-тестом Стьюдента**. Вариант Уэлча (`equal_var=False`) не требует одинакового разброса в группах — его и используют по умолчанию.

```python
from scipy import stats

t = ab_users[ab_users["experiment"] == "checkout_v2"]
a = t.loc[t["group_name"] == "A", "revenue"]
b = t.loc[t["group_name"] == "B", "revenue"]

res = stats.ttest_ind(b, a, equal_var=False)
print(f"ARPU A = {a.mean():.1f} ₽, B = {b.mean():.1f} ₽, p-value = {res.pvalue:.4f}")
```

> 💡 Выручка сильно скошена (большинство пользователей — 0 ₽, у купивших — длинный хвост). t-тест всё равно работает на больших выборках, но разброс большой, поэтому доказать разницу в выручке сложнее, чем в конверсии.

## 4. Доверительный интервал для разницы

Одно p-value говорит «значимо или нет». Бизнесу важнее **насколько**: интервал для разницы конверсий.

```text
SE_diff = √( p_A(1−p_A)/n_A + p_B(1−p_B)/n_B )
разница ± 1,96 × SE_diff
```

«Конверсия выросла на 1,2 п.п. (95% ДИ: от 0,2 до 2,1 п.п.)» — такой вывод понятен и полезен: даже в худшем случае эффект положительный.

## 5. Вывод

Хороший вывод по тесту отвечает на три вопроса:

1. **Что увидели:** конверсия B выше на X п.п. (p = …), ARPU — …
2. **Надёжно ли:** значимо ли, какой интервал, нет ли проблем с данными.
3. **Что делать:** внедрять / не внедрять / продолжить тест / проверить на другом сегменте.

## Отрицательный результат — тоже результат

Второй эксперимент, `banner_color`, скорее всего, не покажет значимой разницы. Это нормально: большинство идей не работает. Вывод «эффекта не обнаружено, оставляем как есть, сэкономили ресурсы на внедрение» — полноценный результат работы аналитика.

## Шпаргалка

| Метрика | Тест | scipy |
|---|---|---|
| конверсия (доля) | z-тест или хи-квадрат | `stats.chi2_contingency(table, correction=False)` |
| среднее (ARPU, чек) | t-тест Уэлча | `stats.ttest_ind(b, a, equal_var=False)` |
| размер эффекта | доверительный интервал разницы | формула выше |
