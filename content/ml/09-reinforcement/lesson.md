## Учиться на последствиях своих действий

В обучении с учителем модель получает готовые правильные ответы. В **обучении с подкреплением (reinforcement learning, RL)** правильных ответов нет: **агент** сам выбирает действия, получает за них **награду** и постепенно учится действовать так, чтобы суммарная награда была больше. Так учатся играть в игры, управлять роботами, торговаться — и так же «дообучают» большие языковые модели по оценкам людей (RLHF).

| Термин | Что это | Пример: лента рекомендаций |
|---|---|---|
| агент | тот, кто принимает решения | алгоритм ленты |
| среда | мир, на который агент действует | пользователь |
| состояние | что агент знает сейчас | история просмотров |
| действие | что агент делает | какой ролик показать |
| награда | число-оценка результата | досмотр, лайк |
| стратегия (policy) | правило выбора действия | «показывать похожее на последние лайки» |

## Исследование или использование

Главная дилемма RL: **использовать** то, что уже кажется лучшим (exploitation), или **исследовать** другие варианты, которые могут оказаться ещё лучше (exploration). Если только использовать, легко навсегда застрять на неплохом, но не лучшем варианте. Если только исследовать, мы будем постоянно тратить показы на заведомо слабые варианты.

## Многорукий бандит

Простейшая задача RL — **многорукий бандит**: есть несколько «рычагов» (баннеров, заголовков, цен), у каждого неизвестная вероятность успеха. Нужно за ограниченное число попыток собрать как можно больше успехов. Для аналитика это прямая альтернатива A/B-тесту.

### ε-жадная стратегия

- с вероятностью `ε` (например, 10%) выбрать случайный вариант — исследовать;
- иначе выбрать вариант с лучшим **наблюдаемым** CTR — использовать.

```python
rng = np.random.default_rng(1)
p_true = np.array([0.04, 0.05, 0.07])     # настоящие CTR — алгоритм их не знает
shows, clicks = np.zeros(3), np.zeros(3)

for step in range(5000):
    explore = rng.random() < 0.1
    random_arm = rng.integers(3)
    ctr = np.divide(clicks, shows, out=np.zeros(3), where=shows > 0)
    arm = random_arm if explore else int(np.argmax(ctr))
    click = rng.random() < p_true[arm]
    shows[arm] += 1
    clicks[arm] += click

print("показы:", shows.astype(int), "клики:", int(clicks.sum()))
print("наблюдаемый CTR:", np.round(clicks / shows, 3))
```

### UCB: оптимизм перед неизвестностью

**UCB1 (upper confidence bound)** добавляет к наблюдаемому CTR «бонус за неизвестность», который велик у редко показанных вариантов:

`UCB = CTR + √(2 · ln N / n)`, где `N` — всего показов, `n` — показов варианта.

Каждый раз выбирается вариант с наибольшим UCB. Вариант, который показывали мало, получает шанс доказать себя. По мере показов бонус тает, и выигрывает реально лучший.

### Сэмплирование Томпсона

Для каждого варианта хранят **бета-распределение** правдоподобных значений CTR: `Beta(клики + 1, показы − клики + 1)`. На каждом шаге из каждого распределения берут случайное число и показывают вариант с наибольшим. Метод естественно балансирует исследование и использование и часто работает лучше всех.

## Бандит или A/B-тест

| | A/B-тест | Бандит |
|---|---|---|
| цель | точно измерить эффект | заработать во время эксперимента |
| трафик | фиксированные доли | постепенно перетекает к лучшему варианту |
| когда | важные решения, долгосрочные метрики | много коротко живущих вариантов: заголовки, баннеры, акции |
| минус | платим за показы худшего варианта | оценка эффекта менее точная, нужна быстрая и однозначная награда |

## Q-обучение (идея)

Когда действия меняют **состояние** (как ходы в игре), агенту нужно оценивать не только мгновенную награду, но и будущие. **Q-обучение** хранит оценку `Q(состояние, действие)` и после каждого шага уточняет её:

`Q ← Q + α · (награда + γ · max Q(следующее состояние) − Q)`

- `α` — скорость обучения;
- `γ` (от 0 до 1) — насколько ценны будущие награды по сравнению с текущими.

Когда состояний слишком много (пиксели экрана в игре), таблицу `Q` заменяют нейросетью — так появилось **глубокое обучение с подкреплением** (DQN, AlphaGo).

```py
import gymnasium as gym                  # стандартная библиотека сред для RL
env = gym.make("CartPole-v1")
state, _ = env.reset()
for _ in range(200):
    action = env.action_space.sample()   # случайная стратегия — отправная точка
    state, reward, done, truncated, _ = env.step(action)
    if done or truncated:
        state, _ = env.reset()
```

## Где RL в работе аналитика

- бандиты для заголовков, баннеров, push-уведомлений, динамических цен;
- рекомендательные системы, которые учатся на реакции пользователей;
- понимание, как дообучают языковые модели;
- ограничения: RL требует много взаимодействий, награду легко задать неудачно («агент нашёл лазейку»), а отлаживать сложно.

## Шпаргалка

| Понятие | Суть |
|---|---|
| агент, среда, действие, награда | словарь RL |
| exploration / exploitation | исследовать новое / использовать лучшее |
| ε-жадная стратегия | с вероятностью ε случайный вариант |
| UCB | CTR + бонус за малое число показов |
| Томпсон | случайная выборка из Beta-распределений |
| Q-обучение | `Q ← Q + α(r + γ·max Q' − Q)` |
