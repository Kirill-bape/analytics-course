## Найти группы без подсказок

В кластеризации нет правильных ответов: алгоритм сам ищет группы **похожих** объектов. Аналитику это нужно для сегментации клиентов, товаров, магазинов, а также для поиска аномалий. В отличие от RFM-сегментов, где границы задаёт человек, кластеризация находит границы по данным.

## Алгоритм k-средних (k-means)

1. Выбрать число кластеров **k** и поставить k **центров** (обычно в случайные объекты).
2. **Шаг назначения**: каждый объект отнести к ближайшему центру.
3. **Шаг обновления**: перенести каждый центр в среднее своих объектов.
4. Повторять шаги 2–3, пока центры не перестанут двигаться.

Качество измеряют **инерцией** — суммой квадратов расстояний объектов до своих центров. Чем она меньше, тем компактнее кластеры.

> ⚠️ k-means считает расстояния, поэтому признаки нужно масштабировать. А скошенные признаки (суммы, число заказов) лучше сначала прологарифмировать, иначе несколько клиентов-гигантов «утянут» центры.

```python
cut = pd.Timestamp("2026-04-01")
hist = orders[orders["order_date"] < cut]
df = hist.groupby("customer_id").agg(frequency=("order_id", "count"), monetary=("amount", "sum"), last=("order_date", "max"))
df["recency"] = (cut - df["last"]).dt.days
df["returned"] = df.index.isin(orders.loc[orders["order_date"] >= cut, "customer_id"]).astype(int)

F = pd.DataFrame({
    "recency": df["recency"],
    "log_frequency": np.log1p(df["frequency"]),
    "log_monetary": np.log1p(df["monetary"]),
})
X = ((F - F.mean()) / F.std()).to_numpy()

def kmeans(X, k, seed=0, iters=100):
    rng = np.random.default_rng(seed)
    centers = X[rng.choice(len(X), k, replace=False)]          # k случайных клиентов
    for _ in range(iters):
        d = ((X[:, None, :] - centers[None, :, :]) ** 2).sum(axis=2)
        labels = d.argmin(axis=1)                              # шаг назначения
        new = np.array([X[labels == j].mean(axis=0) for j in range(k)])   # шаг обновления
        if np.allclose(new, centers):
            break
        centers = new
    inertia = ((X - centers[labels]) ** 2).sum()
    return labels, centers, inertia

labels, centers, inertia = kmeans(X, 3)
profile = df.assign(cluster=labels).groupby("cluster")[["recency", "frequency", "monetary", "returned"]].mean()
profile["clients"] = np.bincount(labels)
print(profile.round(1))
```

## Как понять кластеры

Кластеры — это просто номера. Чтобы с ними работать, строят **профиль**: средние признаков по кластеру и его размер. Затем дают понятные имена. У нас получилось:

| Кластер | Давность | Заказов | Сумма | Вернулись | Имя |
|---|---|---|---|---|---|
| A | ~50 дней | ~12 | ~146 тыс. ₽ | 80% | лояльные |
| B | ~80 дней | ~2 | ~20 тыс. ₽ | 40% | случайные |
| C | ~360 дней | ~1,6 | ~17 тыс. ₽ | 0% | ушедшие |

Кластеры не использовали целевую переменную, но разделили клиентов на группы с очень разной долей вернувшихся. Значит, сегменты осмысленны.

## Сколько кластеров

- **Метод локтя**: посчитать инерцию для k = 1, 2, 3… и найти точку, после которой она снижается медленно («локоть» на графике).
- **Силуэт (silhouette)**: насколько объект ближе к своему кластеру, чем к соседнему (от −1 до 1).
- **Здравый смысл**: сегментов должно быть столько, сколько бизнес сможет различно обслуживать. Десять кластеров, для которых нет разных действий, бесполезны.

Результат k-means зависит от начальных центров, поэтому алгоритм запускают несколько раз с разными зёрнами и берут вариант с наименьшей инерцией.

## Другие методы

| Метод | Идея | Когда |
|---|---|---|
| иерархическая кластеризация | последовательно объединять ближайшие группы, рисовать дерево-дендрограмму | небольшие данные, нужно видеть структуру |
| **DBSCAN** | кластеры — плотные области, редкие точки — выбросы | кластеры сложной формы, поиск аномалий; k задавать не нужно |
| гауссовы смеси (GMM) | мягкая кластеризация: вероятность принадлежности | кластеры пересекаются |

## Снижение размерности: PCA

Когда признаков много и они связаны между собой, их можно заменить несколькими **главными компонентами**: новыми признаками, которые сохраняют бо́льшую часть разброса данных. **Метод главных компонент (PCA)** считается через сингулярное разложение (SVD) стандартизированной матрицы:

```python
p = production.dropna(subset=["downtime_min"])[["planned_units", "produced_units", "defect_units", "downtime_min"]]
Z = ((p - p.mean()) / p.std()).to_numpy()

U, S, Vt = np.linalg.svd(Z, full_matrices=False)
explained = S ** 2 / (S ** 2).sum()
print("доля разброса по компонентам:", np.round(explained, 3))
print("вклад признаков в 1-ю компоненту:", {c: round(float(v), 2) for c, v in zip(p.columns, Vt[0])})
```

Первая компонента почти поровну складывается из плана, выпуска и брака — это «масштаб смены». Она одна объясняет больше 60% разброса четырёх признаков.

Зачем это нужно:

- нарисовать многомерные данные на плоскости (2 компоненты);
- убрать дублирующие друг друга признаки перед моделью;
- сжать данные.

Для визуализации сложных структур используют нелинейные методы **t-SNE** и **UMAP**: они лучше сохраняют соседство точек, но их оси не имеют смысла.

```py
from sklearn.cluster import KMeans, DBSCAN
from sklearn.decomposition import PCA
from sklearn.metrics import silhouette_score

km = KMeans(n_clusters=3, n_init=10, random_state=42).fit(X)
print(km.inertia_, silhouette_score(X, km.labels_))
X2 = PCA(n_components=2).fit_transform(X)
```

## Шпаргалка

| Понятие | Суть |
|---|---|
| k-means | назначить к ближайшему центру → пересчитать центры → повторить |
| инерция | сумма квадратов расстояний до центров |
| локоть | k, после которого инерция падает медленно |
| профиль кластера | средние признаков + размер → имя сегмента |
| DBSCAN | плотные области, выбросы отдельно |
| PCA | главные компоненты через SVD, доля объяснённого разброса |
