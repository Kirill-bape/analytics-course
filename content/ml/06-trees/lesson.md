## Дерево решений

**Дерево решений** — это цепочка вопросов «да/нет» о признаках, как в игре «Угадай животное»:

```text
давность покупки ≤ 100 дней?
├── да: заказов больше одного?
│   ├── да  → вернётся (79% таких вернулись)
│   └── нет → не вернётся (32%)
└── нет → не вернётся (6–21%)
```

Каждый вопрос — **узел**, конечные ответы — **листья**. Предсказание в листе — самый частый класс (для регрессии — среднее) среди обучающих объектов, которые туда попали.

Плюсы деревьев:

- понятны человеку: правила можно показать бизнесу;
- не требуют масштабирования: сравнивают значение с порогом;
- сами ловят нелинейности и взаимодействия признаков («недавно **и** часто»).

## Как дерево выбирает вопрос

На каждом шаге дерево перебирает все признаки и пороги и выбирает разбиение, после которого группы получаются самыми **чистыми** — в каждой преобладает один класс. Чистоту измеряют **индексом Джини**:

`Gini = 1 − p₁² − p₀²`

- 0 — группа чистая (все одного класса);
- 0,5 — максимальная смесь двух классов (50 на 50).

Качество разбиения — средний Джини двух частей, взвешенный по их размеру. Чем он меньше, тем лучше вопрос.

```python
cut = pd.Timestamp("2026-04-01")
hist = orders[orders["order_date"] < cut]
df = hist.groupby("customer_id").agg(frequency=("order_id", "count"), last=("order_date", "max"))
df["recency"] = (cut - df["last"]).dt.days
df["returned"] = df.index.isin(orders.loc[orders["order_date"] >= cut, "customer_id"]).astype(int)

def gini(y):
    p = np.mean(y)
    return 1 - p ** 2 - (1 - p) ** 2

def split_gini(x, y, t):
    left, right = y[x <= t], y[x > t]
    return (len(left) * gini(left) + len(right) * gini(right)) / len(y)

y = df["returned"].to_numpy()
print("Джини до разбиения:", round(gini(y), 3))
for t in [1, 3, 5]:
    print(f"frequency <= {t}:", round(split_gini(df["frequency"].to_numpy(), y, t), 3))
```

Затем то же самое повторяется в каждой из получившихся групп — дерево растёт **рекурсивно**.

## Переобучение деревьев

Если не ограничивать дерево, оно будет делить данные, пока в каждом листе не останется по одному объекту, то есть выучит обучающую выборку наизусть. Поэтому рост ограничивают:

| Параметр | Смысл |
|---|---|
| `max_depth` | максимальная глубина |
| `min_samples_leaf` | минимум объектов в листе |
| `min_samples_split` | минимум объектов, чтобы делить узел |

Глубину подбирают кросс-валидацией: качество на тесте сначала растёт с глубиной, потом падает.

## Ансамбли: много деревьев лучше одного

Одно дерево **нестабильно**: немного другие данные дают совсем другое дерево. Ансамбли объединяют много деревьев.

### Случайный лес (random forest)

1. Сделать много **бутстреп-выборок** — случайных выборок с возвращением из обучающих данных.
2. На каждой вырастить глубокое дерево, причём в каждом узле выбирать лучший вопрос лишь среди **случайной части признаков**.
3. Предсказание — голосование (или среднее) всех деревьев.

Деревья получаются разными, их ошибки частично взаимно гасятся. Лес почти не нужно настраивать, и он устойчив к переобучению.

### Градиентный бустинг

Деревья строятся **последовательно**: каждое новое небольшое дерево исправляет ошибки суммы предыдущих. Бустинг — главный рабочий инструмент на табличных данных: в соревнованиях и в продакшене чаще всего побеждает он.

| Библиотека | Особенности |
|---|---|
| **CatBoost** (Яндекс) | сам работает с категориальными признаками, хорош «из коробки» |
| **LightGBM** (Microsoft) | очень быстрый на больших данных |
| **XGBoost** | классика, много настроек |

```py
from sklearn.tree import DecisionTreeClassifier, export_text
from sklearn.ensemble import RandomForestClassifier
from catboost import CatBoostClassifier

tree = DecisionTreeClassifier(max_depth=2).fit(X_train, y_train)
print(export_text(tree, feature_names=list(X_train.columns)))

forest = RandomForestClassifier(n_estimators=300, min_samples_leaf=5, random_state=42).fit(X_train, y_train)
boost = CatBoostClassifier(iterations=500, depth=6, verbose=False).fit(X_train, y_train, cat_features=["city"])
print(boost.get_feature_importance(prettified=True))
```

## Важность признаков

Деревья умеют показывать **важность признаков**: насколько каждый признак улучшал разбиения. Это полезно, чтобы понять модель, но с оговорками:

- важность — не причинность: «признак важен для предсказания» не значит «изменение признака изменит поведение»;
- признаки с большим числом разных значений (id, точное время) получают завышенную важность;
- для объяснения отдельных предсказаний используют **SHAP**-значения.

## Шпаргалка

| Понятие | Суть |
|---|---|
| узел / лист | вопрос / ответ |
| индекс Джини | `1 − p₁² − p₀²`, 0 — чисто |
| лучший вопрос | минимум взвешенного Джини после разбиения |
| `max_depth`, `min_samples_leaf` | защита от переобучения |
| случайный лес | много деревьев на бутстреп-выборках, голосование |
| бустинг | деревья последовательно исправляют ошибки |
| CatBoost, LightGBM, XGBoost | рабочие лошадки табличного ML |
