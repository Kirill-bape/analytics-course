## Три классических классификатора

Логистическая регрессия — не единственный способ отнести объект к классу. В этом уроке разберём ещё три классических метода, у каждого из которых своя идея:

| Метод | Идея | Сильные стороны |
|---|---|---|
| **k-NN** | «скажи мне, кто твои соседи» | простота, никаких предположений о данных |
| **SVM** | провести границу с максимальным зазором | хорошо работает на небольших данных со многими признаками |
| **наивный Байес** | посчитать вероятности по теореме Байеса | очень быстрый, хорош для текстов |

## k ближайших соседей (k-NN)

Чтобы классифицировать нового клиента, находим **k самых похожих** клиентов из обучающей выборки и смотрим, как поступило большинство. «Похожесть» — это **расстояние** между векторами признаков, обычно евклидово:

`d = √((x₁ − y₁)² + (x₂ − y₂)² + …)`

Обучения в обычном смысле нет: модель просто хранит все примеры. Поэтому предсказание дорогое: для каждого нового объекта нужно посчитать расстояния до всех обучающих.

> ⚠️ Признаки **обязательно** масштабируют, иначе расстояние определит признак с самыми большими числами. Среднее и std считают по обучающей выборке.

```python
cut = pd.Timestamp("2026-04-01")
hist = orders[orders["order_date"] < cut]
df = hist.groupby("customer_id").agg(frequency=("order_id", "count"), last=("order_date", "max"))
df["recency"] = (cut - df["last"]).dt.days
df["returned"] = df.index.isin(orders.loc[orders["order_date"] >= cut, "customer_id"]).astype(int)

rng = np.random.default_rng(42)
idx = rng.permutation(len(df))
n_test = int(len(df) * 0.3)
train, test = df.iloc[idx[n_test:]], df.iloc[idx[:n_test]]

cols = ["recency", "frequency"]
mu, sd = train[cols].mean(), train[cols].std()
Xtr = ((train[cols] - mu) / sd).to_numpy()
Xte = ((test[cols] - mu) / sd).to_numpy()
ytr, yte = train["returned"].to_numpy(), test["returned"].to_numpy()

# расстояния от каждого тестового клиента до каждого обучающего: таблица 588 × 1372
d = np.sqrt(((Xte[:, None, :] - Xtr[None, :, :]) ** 2).sum(axis=2))
nearest = np.argsort(d, axis=1, kind="stable")[:, :5]    # номера 5 ближайших соседей
pred = (ytr[nearest].mean(axis=1) > 0.5).astype(int)     # голосование большинством
print("accuracy k=5:", round((pred == yte).mean(), 3))
```

Конструкция `Xte[:, None, :] - Xtr[None, :, :]` — **транслирование** (broadcasting) numpy: она вычитает каждую обучающую точку из каждой тестовой без циклов.

### Как выбрать k

- маленькое k (1–3) — модель повторяет шум отдельных соседей: **переобучение**;
- большое k — граница сглаживается, и модель теряет детали: **недообучение**;
- k подбирают кросс-валидацией и обычно берут нечётным, чтобы голосование не заканчивалось ничьёй.

## Метод опорных векторов (SVM)

SVM проводит между классами границу так, чтобы **зазор** (расстояние до ближайших точек обоих классов) был максимальным. Ближайшие к границе точки называют **опорными векторами** — только они и определяют модель.

Если классы нельзя разделить прямой (например, один класс окружает другой), помогает **ядро (kernel)**. Оно неявно переносит данные в пространство, где граница становится прямой. Самое популярное — RBF-ядро.

```py
from sklearn.svm import SVC
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import make_pipeline

svm = make_pipeline(StandardScaler(), SVC(kernel="rbf", C=1.0, probability=True))
svm.fit(X_train, y_train)
```

Параметр `C` задаёт компромисс: большое `C` строже штрафует ошибки на обучении и рискует переобучиться. На больших таблицах (сотни тысяч строк) SVM медленный, поэтому в аналитике его используют реже бустинга.

## Наивный Байес

**Теорема Байеса** пересчитывает вероятность гипотезы после наблюдения:

`P(класс | признак) = P(признак | класс) × P(класс) / P(признак)`

Пример со спамом: 20% писем — спам; слово «выигрыш» встречается в 60% спама и в 5% обычных писем. Тогда для письма со словом «выигрыш»:

- `P(спам) × P(слово | спам) = 0,2 × 0,6 = 0,12`;
- `P(не спам) × P(слово | не спам) = 0,8 × 0,05 = 0,04`;
- `P(спам | слово) = 0,12 / (0,12 + 0,04) = 0,75`.

**Наивный** Байес считает признаки независимыми друг от друга при известном классе. Тогда вероятности по отдельным словам просто перемножаются. Предположение почти всегда неверно, но метод всё равно хорошо работает на текстах: фильтры спама, классификация обращений в поддержку. Он очень быстрый и служит хорошим baseline.

```py
from sklearn.feature_extraction.text import CountVectorizer
from sklearn.naive_bayes import MultinomialNB

vec = CountVectorizer()
X = vec.fit_transform(texts)          # «мешок слов»: сколько раз встретилось каждое слово
nb = MultinomialNB().fit(X, labels)
```

## Шпаргалка

| Метод | Главный параметр | Помни |
|---|---|---|
| k-NN | k — число соседей | масштабировать признаки; дорогое предсказание |
| SVM | `C`, ядро | масштабировать; медленный на больших данных |
| наивный Байес | сглаживание `alpha` | быстрый baseline для текстов |
| евклидово расстояние | `np.linalg.norm(a - b)` | |
| ближайшие соседи | `np.argsort(d, axis=1)[:, :k]` | |
