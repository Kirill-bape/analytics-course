## BI, которые встречаются в вакансиях

После ухода западных вендоров в российских компаниях чаще всего встречаются:

| Инструмент | Что это | Особенности |
|---|---|---|
| **Yandex DataLens** | облачная BI от Яндекса, есть бесплатный тариф | работает в браузере, быстро стартовать, удобна для ClickHouse |
| **Apache Superset** | open source, ставится на свой сервер | SQL Lab для запросов, много типов графиков, гибкие права |
| **Metabase** | open source | очень простой интерфейс, вопросы к данным «без SQL» |
| **Redash** | open source | «запрос → график → дашборд», удобен тем, кто пишет SQL |
| **FineBI, Visiology, Luxms, Модус** | российские коммерческие BI | замена Power BI и Tableau в крупном бизнесе |
| **Looker Studio** | бесплатная BI от Google | популярна в маркетинге, особенно с рекламными источниками |

Логика везде одинаковая: **подключение → датасет → чарты → дашборд**. Освоил одну систему — во второй разберёшься за пару дней.

## DataLens: из чего состоит

1. **Подключение** — доступ к источнику: ClickHouse, PostgreSQL, Метрика, загруженные CSV и Excel, Google Таблицы.
2. **Датасет** — описание данных для графиков: какие таблицы и как связаны, какие поля, их типы и агрегация по умолчанию. Здесь же создают **вычисляемые поля**.
3. **Чарт** — график, построенный мастером: перетаскиваешь поля в «X», «Y», «Цвета», «Фильтры».
4. **Дашборд** — чарты, тексты и **селекторы** (фильтры) на одной странице. Связи между селекторами и чартами настраиваются: какой фильтр на какой график действует.

Вычисляемые поля пишутся на собственном языке формул, похожем на Excel и SQL:

```text
Выручка        SUM_IF([amount], [status] = "delivered")
Средний чек    [Выручка] / COUNTD_IF([order_id], [status] = "delivered")
Месяц          DATETRUNC([order_date], "month")
Год назад      AGO([Выручка], [order_date], "year")
```

`AGO` — функция «значение год назад» без самосоединений, аналог `SAMEPERIODLASTYEAR` в Power BI.

> 💡 В DataLens агрегация задаётся в формуле или в настройке поля. Частая ошибка — сложить уже усреднённое значение: средний чек по городам, сложенный в итоге, даст бессмыслицу. Средние и доли считай отношением сумм.

## Superset: SQL прямо в BI

В Superset есть **SQL Lab** — редактор запросов к подключённым базам. Хороший запрос можно сразу сохранить как **виртуальный датасет** и строить по нему графики. Для аналитика, который знает SQL, это самый быстрый путь: сложную логику пишешь запросом, а BI только рисует.

```sql
-- Виртуальный датасет для дашборда продаж: одна строка = один день
SELECT o.order_date,
       c.city,
       c.acquisition_channel,
       COUNT(*)                                          AS orders,
       COUNT(*) FILTER (WHERE o.status = 'delivered')    AS delivered,
       SUM(o.amount) FILTER (WHERE o.status = 'delivered') AS revenue
FROM orders o
JOIN customers c ON c.customer_id = o.customer_id
GROUP BY o.order_date, c.city, c.acquisition_channel
ORDER BY o.order_date DESC
LIMIT 10;
```

В чарте поверх такого датасета задают метрики (`SUM(revenue)`, `SUM(revenue) / SUM(delivered)`), группировки и фильтр по времени. На дашборде добавляют **нативные фильтры**: период, город, канал — они применяются сразу ко всем чартам.

## Предагрегация: чтобы дашборд не тормозил

Дашборд, который при каждом открытии пересчитывает миллиард строк сырых событий, будет открываться минуту. Поэтому под дашборд готовят **витрину** — заранее агрегированную таблицу: по дням, городам, каналам. Обновляют её по расписанию (раз в час или раз в сутки). Как именно — расскажем в модуле про хранилища данных и Airflow.

Важная тонкость предагрегации: **уникальные значения нельзя складывать**. Если в витрине по дням есть «число уникальных клиентов», сумма за месяц будет больше настоящего числа уникальных клиентов за месяц: один клиент, купивший в два разных дня, посчитается дважды.

## Как выбрать инструмент

- Компания уже работает с Яндекс Облаком и ClickHouse → **DataLens**.
- Нужен свой сервер, бесплатная лицензия и аналитики, которые пишут SQL → **Superset**.
- Много нетехнических пользователей, которые задают простые вопросы → **Metabase**.
- Корпоративные требования, интеграция с 1С и поддержка вендора → российские коммерческие BI.

Для портфолио новичку проще всего **DataLens**: бесплатно, в браузере, а ссылку на публичный дашборд можно вставить в резюме. Пошаговый план — в теме «Дашборд в BI-инструменте».

## Шпаргалка

| Понятие | DataLens | Superset |
|---|---|---|
| источник | подключение | database |
| описание данных | датасет | датасет (физический или виртуальный из SQL) |
| формулы | вычисляемые поля: `SUM_IF`, `COUNTD`, `AGO` | метрики и вычисляемые колонки датасета |
| график | чарт (мастер чартов) | chart |
| фильтры на дашборде | селекторы и связи | нативные фильтры |
| запросы руками | QL-чарт | SQL Lab |
