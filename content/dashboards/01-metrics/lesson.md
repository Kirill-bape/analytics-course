## Метрика — число, по которому принимают решения

**Метрика** — показатель, который регулярно считают, чтобы понимать, как идут дела. **KPI** (Key Performance Indicator) — ключевые метрики, по которым оценивают успех команды или бизнеса. Дашборд — это витрина метрик. Поэтому сначала нужно понять, **что** показывать.

## Главные метрики интернет-магазина

| Метрика | Как считается | Что показывает |
|---|---|---|
| **Выручка** (Revenue, GMV) | сумма доставленных заказов | масштаб бизнеса |
| **Число заказов** | количество заказов | активность |
| **Покупатели** | число уникальных клиентов с заказом | охват |
| **Средний чек** (AOV) | выручка / число заказов | сколько тратят за раз |
| **Конверсия** (CR) | покупатели / посетители × 100% | насколько хорошо сайт продаёт |
| **ARPU** | выручка / число пользователей | доход на пользователя |
| **Доля повторных покупок** | клиенты с 2+ заказами / все покупатели | лояльность |
| **Retention** (удержание) | доля клиентов, вернувшихся через N дней | возвращаются ли клиенты |
| **LTV** | выручка с клиента за всё время | ценность клиента |
| **CAC** | затраты на рекламу / число новых клиентов | цена привлечения |

Главное соотношение юнит-экономики: **LTV должен быть больше CAC** — иначе каждый новый клиент приносит убыток.

## Как метрики связаны

Метрики образуют дерево. Выручка раскладывается на множители:

```text
Выручка = Покупатели × Заказов на покупателя × Средний чек
```

Если выручка упала, по дереву видно, где искать причину: стало меньше покупателей? Они реже заказывают? Меньше тратят за раз?

## Считаем KPI на SQL

```sql
SELECT SUM(amount)                  AS revenue,
       COUNT(*)                     AS orders_cnt,
       COUNT(DISTINCT customer_id)  AS buyers,
       ROUND(SUM(amount) / COUNT(*), 0) AS aov
FROM orders
WHERE status = 'delivered'
  AND order_date >= '2026-06-01';
```

## North Star — метрика «полярной звезды»

Команде полезно иметь одну главную метрику, которая лучше всего отражает ценность для клиента и бизнеса. Для интернет-магазина это часто «число доставленных заказов в неделю» или «выручка от повторных покупателей». Остальные метрики — её составляющие.

## Хорошая метрика

- **Понятная:** одно определение, записанное словами («доставленные заказы, без отменённых и возвратов»).
- **Сравнимая:** с прошлым периодом, с планом, между сегментами.
- **Влияющая на решения:** если метрика изменилась, понятно, что делать.

> ⚠️ Одна из самых частых проблем в компаниях — разные отделы считают «выручку» по-разному. Поэтому у каждой метрики на дашборде должно быть записанное определение.

## Шпаргалка

| Метрика | Формула |
|---|---|
| средний чек | выручка / заказы |
| конверсия | покупатели / посетители |
| ARPU | выручка / пользователи |
| доля повторных | клиенты с 2+ заказами / покупатели |
| юнит-экономика | LTV > CAC |
