## Итоги по группам

В модуле «Основы SQL» агрегатные функции сворачивали **всю** таблицу в одно число: «выручка — 154 млн». Но руководителю нужно другое: выручка **по каждому** способу оплаты, **по каждому** месяцу, **по каждой** категории. Для этого есть `GROUP BY` — «сгруппировать по».

```sql
SELECT status, COUNT(*) AS orders_cnt
FROM orders
GROUP BY status;
```

Как это работает:

1. База раскладывает строки по «кучкам» с одинаковым значением `status`.
2. Для каждой кучки считает `COUNT(*)`.
3. Каждая кучка превращается в **одну строку** результата.

Это то же самое, что сводная таблица в Excel: `GROUP BY` — это «Строки», агрегатная функция — «Значения».

## Главное правило GROUP BY

В `SELECT` можно писать только:

- столбцы, **по которым группируем** (они есть в `GROUP BY`);
- **агрегатные функции** (`COUNT`, `SUM`, `AVG`, `MIN`, `MAX`).

Любой другой столбец вызовет ошибку: у одной группы много разных значений, и база не знает, какое показать.

## Группировка с фильтром и сортировкой

`WHERE` отбирает строки **до** группировки, `ORDER BY` сортирует **готовые** группы:

```sql
SELECT payment_method,
       COUNT(*)              AS orders_cnt,
       SUM(amount)           AS revenue,
       ROUND(AVG(amount), 2) AS avg_check
FROM orders
WHERE status = 'delivered'
GROUP BY payment_method
ORDER BY revenue DESC;
```

> 💡 В `ORDER BY` можно ссылаться на псевдоним (`revenue`) — сортировка выполняется в самом конце, когда псевдонимы уже известны.

## Порядок выполнения запроса

Запрос пишется в одном порядке, а выполняется в другом — это объясняет многие ошибки:

| Порядок выполнения | Что происходит |
|---|---|
| 1. `FROM` | берём таблицу |
| 2. `WHERE` | отбрасываем лишние строки |
| 3. `GROUP BY` | раскладываем по группам |
| 4. `HAVING` | отбрасываем лишние группы (следующая тема) |
| 5. `SELECT` | считаем столбцы и агрегаты |
| 6. `ORDER BY` | сортируем |
| 7. `LIMIT` | обрезаем |

## Группировка по месяцам

Самый частый отчёт — динамика по месяцам. Дату «обрезают» до начала месяца и группируют по ней:

```sql
-- chart: line
SELECT CAST(date_trunc('month', order_date) AS DATE) AS month,
       SUM(amount) AS revenue
FROM orders
WHERE status = 'delivered'
GROUP BY month
ORDER BY month;
```

Видно сезонность: пик в ноябре–декабре (Чёрная пятница и Новый год), провал в январе. `CAST(… AS DATE)` убирает из результата время `00:00:00`.

> 💡 Строку `-- chart: line` в начале примера понимает это приложение: под результатом появится график. Для базы это просто комментарий.

## Группировка по нескольким столбцам

Можно группировать сразу по нескольким столбцам — тогда группа это каждое **сочетание** значений:

```sql
SELECT line_id, shift,
       SUM(produced_units) AS produced,
       SUM(defect_units)   AS defects
FROM production
GROUP BY line_id, shift
ORDER BY line_id, shift;
```

Это данные завода: сколько изделий выпустила каждая линия в дневную и ночную смены.

## Шпаргалка

```text
SELECT   столбец_группы, АГРЕГАТ(...) AS имя
FROM     таблица
WHERE    условие_на_строки
GROUP BY столбец_группы
ORDER BY имя DESC;
```
