## График — это ответ на вопрос

Хороший график начинается не с выбора красивого типа, а с вопроса: **что должен увидеть читатель?** Сравнение? Динамику? Распределение? Связь? Каждой задаче — свой тип графика.

## Какой график для какой задачи

| Задача | Вопрос | График |
|---|---|---|
| **Сравнение** категорий | Какая категория продаёт больше? | столбчатая (bar), лучше горизонтальная |
| **Динамика** во времени | Как менялась выручка по месяцам? | линейный (line) |
| **Распределение** | Какие бывают суммы заказов? | гистограмма |
| **Связь** двух величин | Связаны ли простои и выпуск? | точечная (scatter) |
| **Доля** от целого | Какая доля заказов оплачена картой? | столбцы с долями; круговая — только если частей 2–3 |
| **Одно ключевое число** | Какая выручка за месяц? | не график, а крупная цифра (KPI) |

## Столбчатая диаграмма — сравнение

Длину столбцов глаз сравнивает очень точно. Правила: столбцы **начинаются с нуля**, отсортированы по значению, а если подписи длинные — столбцы **горизонтальные**.

```sql
-- chart: bar
SELECT p.category, SUM(oi.quantity * oi.price) AS revenue
FROM order_items oi
JOIN products p USING (product_id)
GROUP BY p.category
ORDER BY revenue DESC;
```

## Линейный график — динамика

Линия показывает изменение во времени: рост, падение, сезонность. По оси X — время, всегда по порядку.

```sql
-- chart: line
SELECT CAST(date_trunc('month', order_date) AS DATE) AS month, COUNT(*) AS orders_cnt
FROM orders
GROUP BY month
ORDER BY month;
```

## Гистограмма — распределение

Похожа на столбчатую, но по оси X — **интервалы числа** (суммы заказа по 5 000 ₽), а высота столбца — сколько значений попало в интервал. Показывает форму распределения, о которой мы говорили в модуле статистики.

## Точечная диаграмма — связь

Каждая точка — один объект (смена, клиент), координаты — две его характеристики. Если точки выстраиваются в наклонное «облако» — величины связаны. Строить её будем в Python в следующей теме.

## Круговая диаграмма — осторожно

Круговую («пирог») любят, но глаз плохо сравнивает углы. Она уместна только для 2–3 частей одного целого. В остальных случаях столбцы с процентами читаются лучше.

> 💡 Если на графике больше 5–7 линий или цветов, читатель запутается. Выдели главное (одну-две серии), остальное сделай серым или вынеси в отдельные маленькие графики.

## Шпаргалка

| Хочу показать | Выбираю |
|---|---|
| кто больше | столбцы |
| как менялось | линия |
| как распределено | гистограмма |
| связаны ли | точки |
| одно число | KPI-карточка |
