## Сводная таблица — главный инструмент Excel-аналитика

Представь 15 000 заказов. Руководитель спрашивает: «Какая выручка по каждому городу? А по месяцам? А по городам и месяцам сразу?» Считать это формулами долго. **Сводная таблица** (pivot table) делает это за несколько кликов: она группирует строки и считает итоги — как `GROUP BY` в SQL.

## Из чего состоит сводная

Сводная собирается перетаскиванием полей (столбцов исходной таблицы) в четыре области:

| Область | Что туда класть | Пример | Аналог в SQL |
|---|---|---|---|
| **Строки** | по чему группировать | Город | `GROUP BY city` |
| **Столбцы** | вторая группировка — «в ширину» | Месяц | — |
| **Значения** | что считать и как (сумма, количество, среднее) | Сумма заказа → Сумма | `SUM(amount)` |
| **Фильтры** | какие строки учитывать | Статус = delivered | `WHERE status = 'delivered'` |

Итог: таблица, где по строкам — города, по столбцам — месяцы, а в ячейках — выручка.

## Как создать сводную

**В Excel:** выдели таблицу → Вставка → Сводная таблица → Новый лист. Справа появится список полей — перетаскивай их в области.

**В Google Таблицах:** Вставка → Создать сводную таблицу → в редакторе справа добавляй «Строки», «Столбцы», «Значения», «Фильтры».

Полезные настройки значений:

- **Сумма / Количество / Среднее** — как считать (по умолчанию для чисел — сумма, для текста — количество);
- **Показать как % от итога** — доля каждой строки;
- **Сортировка** по значению — чтобы сверху были лидеры.

> 💡 Важно: сводная не обновляется сама. Изменились данные — нажми «Обновить» (Excel: Анализ сводной таблицы → Обновить).

## Сводная вручную: СУММЕСЛИ по списку

Во встроенной таблице кнопки «Сводная» нет, но то же самое можно сделать формулами — это полезно и в реальной работе, когда нужен отчёт в фиксированном виде.

1. Выпиши список значений группировки (например, городов) в отдельный столбец.
2. Рядом посчитай итог для каждого через `СУММЕСЛИ`, закрепив диапазоны данных:

```text
=СУММЕСЛИ($A$2:$A$41; F2; $C$2:$C$41)
```

Здесь `$A$2:$A$41` — города в данных, `F2` — город из списка (без `$`, чтобы при протягивании менялся), `$C$2:$C$41` — суммы.

Так же считаются количество (`СЧЁТЕСЛИ`) и среднее (`СРЗНАЧЕСЛИ`) по группам.

## Как читать сводную

Сводная — это не ответ, а материал для вывода. Хорошая привычка: после каждой сводной сформулируй **одну фразу-вывод**. Например: «Москва даёт половину выручки, но средний чек выше в Санкт-Петербурге».

## Шпаргалка

| Задача | Как |
|---|---|
| итог по группам | сводная: Строки + Значения |
| таблица «город × месяц» | Строки + Столбцы + Значения |
| только доставленные | поле «Статус» в Фильтры |
| доля от итога | Значения → Показать как % от общей суммы |
| то же формулами | `=СУММЕСЛИ($A$2:$A$41;F2;$C$2:$C$41)` |
