## Функции — готовые формулы

Функция — это готовый расчёт с названием. Пишется так: `=НАЗВАНИЕ(аргументы)`, а аргументы разделяются точкой с запятой `;`.

| Функция | Что считает | Аналог в SQL |
|---|---|---|
| `=СУММ(E2:E16)` | сумма | `SUM` |
| `=СРЗНАЧ(E2:E16)` | среднее | `AVG` |
| `=МИН(E2:E16)`, `=МАКС(E2:E16)` | минимум, максимум | `MIN`, `MAX` |
| `=СЧЁТ(E2:E16)` | сколько ячеек с **числами** | `COUNT` |
| `=СЧЁТЗ(A2:A16)` | сколько **непустых** ячеек | `COUNT` |
| `=ОКРУГЛ(E2;2)` | округлить до 2 знаков | `ROUND` |

Функции можно вкладывать друг в друга: `=ОКРУГЛ(СРЗНАЧ(E2:E16);2)` — средний чек, округлённый до копеек.

## Условие: ЕСЛИ

`=ЕСЛИ(условие; значение_если_да; значение_если_нет)` — это `CASE WHEN` из SQL.

| Формула | Результат |
|---|---|
| `=ЕСЛИ(E2>=10000;"крупный";"обычный")` | «крупный», если сумма от 10 000 |
| `=ЕСЛИ(D2="cancelled";0;E2)` | 0 для отменённых, иначе сумма |
| `=ЕСЛИ(E2>=10000;"крупный";ЕСЛИ(E2>=3000;"средний";"маленький"))` | три группы — вложенные ЕСЛИ |

Текст в формулах пишут в **двойных** кавычках: `"крупный"` (в SQL — в одинарных, не перепутай).

Для нескольких условий есть `И(...)` и `ИЛИ(...)`: `=ЕСЛИ(И(E2>5000;D2="delivered");"да";"нет")`.

## Абсолютные ссылки: знак $

При протягивании адреса сдвигаются. Но иногда ссылка должна **стоять на месте** — например, на общую сумму, чтобы посчитать долю каждого заказа.

`=E2/СУММ(E2:E16)` в первой строке работает, но при протягивании превратится в `=E3/СУММ(E3:E17)` — диапазон «уехал», и доли посчитаются неправильно.

Решение — закрепить диапазон знаком `$`: `=E2/СУММ($E$2:$E$16)`. Теперь при протягивании меняется только `E2`, а `$E$2:$E$16` остаётся на месте.

| Запись | Что закреплено |
|---|---|
| `E2` | ничего — сдвигается всё |
| `$E$2` | и столбец, и строка |
| `$E2` | только столбец |
| `E$2` | только строка |

> 💡 В Excel знаки `$` расставляет клавиша **F4**: поставь курсор на адрес и нажми её.

## Функции с условием: СЧЁТЕСЛИ и СУММЕСЛИ

Это «мини-SQL» внутри таблицы — самые полезные функции для аналитика:

| Функция | Что делает | SQL-аналог |
|---|---|---|
| `=СЧЁТЕСЛИ(D2:D16;"delivered")` | сколько доставленных | `COUNT(*) WHERE status = 'delivered'` |
| `=СУММЕСЛИ(D2:D16;"delivered";E2:E16)` | сумма доставленных | `SUM(amount) WHERE status = 'delivered'` |
| `=СРЗНАЧЕСЛИ(C2:C16;"Москва";E2:E16)` | средний чек Москвы | `AVG(amount) WHERE city = 'Москва'` |
| `=СЧЁТЕСЛИ(E2:E16;">10000")` | сколько больше 10 000 | `COUNT(*) WHERE amount > 10000` |

Устройство `СУММЕСЛИ`: **где проверяем условие; какое условие; что складываем**.

Условия с сравнением пишут в кавычках: `">10000"`, `"<>cancelled"` (не равно).

Для нескольких условий — `СУММЕСЛИМН` и `СЧЁТЕСЛИМН`:
`=СУММЕСЛИМН(E2:E16;D2:D16;"delivered";C2:C16;"Москва")` — сумма доставленных заказов из Москвы. Внимание: здесь **сначала** диапазон суммирования.

## Шпаргалка

| Задача | Формула |
|---|---|
| итог | `=СУММ(E2:E16)` |
| среднее с округлением | `=ОКРУГЛ(СРЗНАЧ(E2:E16);2)` |
| если–то–иначе | `=ЕСЛИ(E2>=10000;"да";"нет")` |
| доля от итога | `=E2/СУММ($E$2:$E$16)` |
| сумма по условию | `=СУММЕСЛИ(D2:D16;"delivered";E2:E16)` |
| количество по условию | `=СЧЁТЕСЛИ(D2:D16;"cancelled")` |
