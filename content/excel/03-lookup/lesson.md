## Зачем искать значения в другой таблице

Данные почти всегда лежат в разных таблицах: в одной — заказы с номером клиента, в другой — клиенты с городом. Чтобы узнать город для каждого заказа, нужно **найти** клиента во второй таблице и подтянуть нужное поле.

В SQL для этого есть `JOIN` (будет в продвинутом модуле), а в Excel — функции **ВПР** и **ПРОСМОТРX**. На собеседованиях про ВПР спрашивают почти всегда.

## ВПР — вертикальный поиск

```text
=ВПР(что_ищем; где_ищем; номер_столбца; 0)
```

1. **что ищем** — значение, например ID клиента из ячейки `B2`;
2. **где ищем** — таблица-справочник. Искомое значение должно быть в её **первом** (левом) столбце;
3. **номер столбца** — из какого столбца справочника взять ответ (1 — первый, 2 — второй…);
4. **0** (или `ЛОЖЬ`) — искать **точное** совпадение. Почти всегда нужен именно 0.

Пример: справочник клиентов в `G2:I30` (G — ID, H — город, I — канал).

| Формула | Результат |
|---|---|
| `=ВПР(B2;$G$2:$I$30;2;0)` | город клиента из B2 |
| `=ВПР(B2;$G$2:$I$30;3;0)` | канал привлечения |

Справочник закрепляют знаками `$` — иначе при протягивании он «уедет» вниз, и часть клиентов перестанет находиться.

> ⚠️ Без последнего аргумента `0` ВПР ищет **приблизительное** совпадение и может молча вернуть чужие данные. Это одна из самых коварных ошибок в Excel.

## Ошибка #Н/Д

`#Н/Д` значит «не найдено». Частые причины:

- искомого значения действительно нет в справочнике;
- лишние пробелы: `"Москва "` ≠ `"Москва"`;
- число записано как текст: `"123"` ≠ `123`;
- справочник «уехал» при протягивании (забыт `$`);
- искомый столбец в справочнике не первый.

## ЕСЛИОШИБКА — вежливый ответ вместо ошибки

`=ЕСЛИОШИБКА(формула; что_показать_при_ошибке)`:

```text
=ЕСЛИОШИБКА(ВПР(B2;$G$2:$H$30;2;0);"нет данных")
```

Если клиент найден — будет город, если нет — «нет данных» вместо `#Н/Д`.

## ПРОСМОТРX — современная замена ВПР

В новых версиях Excel и в Google Таблицах есть **ПРОСМОТРX** (XLOOKUP). Она удобнее:

```text
=ПРОСМОТРX(что_ищем; где_ищем; что_вернуть)
```

`=ПРОСМОТРX(B2;$G$2:$G$30;$I$2:$I$30)` — найти B2 в столбце ID и вернуть значение из столбца «Канал».

Плюсы: не нужно считать номер столбца, искомый столбец не обязан быть первым, по умолчанию ищет точное совпадение. Четвёртым аргументом можно задать текст «если не найдено».

> 💡 В старых версиях Excel ПРОСМОТРX нет, поэтому ВПР всё равно нужно знать. Ещё встречается связка `ИНДЕКС` + `ПОИСКПОЗ` — она делает то же, что ПРОСМОТРX.

## Шпаргалка

| Задача | Формула |
|---|---|
| найти значение | `=ВПР(B2;$G$2:$I$30;2;0)` |
| то же, современно | `=ПРОСМОТРX(B2;$G$2:$G$30;$H$2:$H$30)` |
| без ошибки #Н/Д | `=ЕСЛИОШИБКА(ВПР(...);"нет данных")` |
