## Что такое база данных

Представь Excel-файл с несколькими листами. Каждый лист — это **таблица**: у неё есть **столбцы** (что мы знаем: имя, город, цена) и **строки** (конкретные записи: один клиент, один заказ).

**База данных** — это много таких таблиц, которые хранятся вместе и связаны между собой. В настоящих компаниях в таблицах миллионы строк, поэтому аналитик не листает их глазами. Он пишет **запрос** на языке **SQL** (читается «эс-кью-эль» или «сиквел»), и база сама находит, считает и возвращает нужное.

SQL — навык номер один для аналитика: его спрашивают почти в каждой вакансии и на каждом собеседовании.

В этом курсе у нас база данных интернет-магазина:

| Таблица | Что в ней | Строк |
|---|---|---|
| `customers` | клиенты: имя, город, дата регистрации | 3 000 |
| `products` | товары: название, категория, цена | 131 |
| `orders` | заказы: дата, статус, сумма | ≈ 15 000 |
| `order_items` | какие товары лежали в каждом заказе | ≈ 25 000 |

> 💡 Все таблицы и столбцы с описанием есть в панели **«Схема данных»** — кнопка справа внизу. Заглядывай туда, когда не помнишь название столбца.

## Первый запрос

Самый простой запрос — «покажи всё из таблицы»:

```sql
SELECT * FROM products;
```

Он читается почти как английское предложение:

- `SELECT` — «выбери»;
- `*` — «все столбцы»;
- `FROM products` — «из таблицы products»;
- `;` — конец запроса (как точка в конце предложения).

Нажми **▶ Запустить пример** — запрос выполнится прямо здесь. Примеры можно менять и запускать снова: ничего не сломается, а кнопка «Вернуть как было» восстановит исходный текст.

## Выбираем нужные столбцы

Обычно все столбцы не нужны. Перечисли нужные через запятую:

```sql
SELECT product_name, category, price
FROM products;
```

Столбцы появятся в результате в том порядке, в котором они перечислены.

## Ограничиваем число строк: LIMIT

Таблица заказов большая. Чтобы просто посмотреть, как выглядят данные, берут несколько первых строк:

```sql
SELECT *
FROM orders
LIMIT 5;
```

> 💡 Привычка хорошего аналитика: прежде чем работать с незнакомой таблицей, посмотри на неё через `LIMIT 10`. Сразу видно, какие там столбцы и какие значения.

## Переименовываем столбцы: AS

Слово `AS` даёт столбцу в результате другое имя — **псевдоним**. Сама таблица при этом не меняется.

```sql
SELECT product_name AS name, price AS price_rub
FROM products
LIMIT 5;
```

Псевдонимы нужны, чтобы результат был понятнее. Особенно пригодятся, когда начнём считать новые столбцы.

## Правила написания

- **Регистр ключевых слов не важен:** `select` = `SELECT`. Но принято писать их большими буквами — так запрос легче читать.
- **Переносы строк и пробелы не важны.** Пиши так, как удобнее читать: обычно каждая часть запроса — с новой строки.
- **Между столбцами — запятая**, а после последнего столбца запятой нет.
- Всё, что после `--`, — **комментарий**. База его пропускает. Удобно для заметок самому себе.

```sql
-- Посмотрим на клиентов
SELECT full_name, city  -- только имя и город
FROM customers
LIMIT 3;
```

## Частые ошибки

| Ошибка | Что не так |
|---|---|
| `SELECT product_name, price, FROM products` | Лишняя запятая перед `FROM`. Наша база (DuckDB) её прощает, но PostgreSQL и большинство других баз выдадут ошибку — не привыкай так писать |
| `SELECT product_name price FROM products` | Забыта запятая. Коварно: ошибки не будет, SQL решит, что `price` — это новое имя для столбца `product_name`! |
| `SELECT * FORM products` | Опечатка в `FROM` — приложение подскажет, где именно |

## Шпаргалка

```text
SELECT столбец1, столбец2   -- что показать
FROM таблица                -- откуда
LIMIT 10;                   -- сколько строк
```
