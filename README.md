# Путь аналитика

Приложение для самостоятельного изучения аналитики данных: уроки простым языком, задания с автоматической проверкой, прогресс и план до января.

**Внутри:** 9 модулей, 45 тем, 216 заданий — Excel, SQL (основы и продвинутый), статистика, Python и pandas, визуализация, дашборды, A/B-тесты и итоговый проект для портфолио. Работает на компьютере, телефоне, раскладушке, iPad и MacBook — **без интернета** и без платных сервисов.

## Где заниматься

| Устройство | Как открыть |
|---|---|
| **Компьютер (Windows)** | двойной клик по `start.bat` — см. ниже |
| **Телефон Samsung / Android** | приложение APK: скачать по ссылке на странице «Настройки» или в разделе Releases на GitHub |
| **iPad, iPhone** | сайт на GitHub Pages в Safari → «Поделиться» → «На экран „Домой"» |
| **MacBook** | тот же сайт в Safari → «Файл» → «Добавить в Dock» |

После первого открытия сайт сам скачивает всё нужное (около 85 МБ, лучше по Wi-Fi) и дальше работает без интернета, включая базу данных и Python. В APK всё уже внутри.

## Как запустить на компьютере

**Способ 1 — двойной клик.** Открой папку `analytics-course` и дважды щёлкни по файлу `start.bat`. Откроется чёрное окно, а через пару секунд — браузер с приложением.

**Способ 2 — одна команда** в терминале:

```
npm --prefix "C:\Users\Админ\analytics-course" start
```

Приложение откроется по адресу <http://127.0.0.1:3000>. Пока занимаешься, **не закрывай чёрное окно** — это сервер приложения. Закончил — закрой окно.

> Если PowerShell пишет, что «выполнение сценариев отключено», используй `npm.cmd` вместо `npm` или запускай через `start.bat`.

> Если после обновления курса не видно новых тем — закрой чёрное окно и запусти `start.bat` заново.

## Где хранится прогресс

Прогресс хранится **на самом устройстве** — в памяти браузера или Android-приложения. Сервер и регистрация не нужны.

- **Перенос между устройствами:** «Настройки» → «Сохранить прогресс в файл» → передай файл (Telegram, почта, Google Диск, AirDrop) → на другом устройстве «Настройки» → «Загрузить из файла».
- **Загрузка ничего не стирает — прогресс объединяется:** задание считается решённым, если оно решено хотя бы на одном устройстве, дни занятий складываются.
- Раз в неделю приложение напоминает сохранить копию: если удалить приложение или очистить данные браузера, прогресс на устройстве пропадёт, а файл останется.
- На компьютере (запуск через `start.bat`) прогресс дополнительно копируется в файл `progress.json` в папке проекта.

## Телефон, планшет, компьютер

Интерфейс подстраивается под экран:

- **телефон и внешний экран раскладушки** — меню внизу, крупные кнопки;
- **iPad вертикально и внутренний экран раскладушки** — узкая колонка значков слева;
- **компьютер, MacBook, iPad горизонтально** — боковое меню со статистикой.

Когда пишешь код на телефоне или планшете, над клавиатурой появляется **панель быстрых символов**: `' ( ) , * = ;` и частые слова (`SELECT`, `FROM`, `WHERE`, `GROUP BY`… для SQL, `df`, `.groupby(`, `print(`… для Python, `СУММ(`, `ВПР(`… для таблиц), стрелки для курсора и кнопки «Запустить» / «Проверить».

## Виды заданий

| Тип | Как выглядит | Как проверяется |
|---|---|---|
| SQL | редактор запросов, база DuckDB | результат сравнивается с эталонным запросом |
| Python | редактор кода, Python + pandas в браузере | переменная `result`, вывод `print` или график |
| Таблица | встроенная электронная таблица с формулами Excel по-русски | значения в нужных ячейках |
| Тест | варианты ответа | правильный вариант, с объяснением каждого |
| Ответ-число | поле для числа | число с учётом округления и типичных ошибок |
| Чек-лист | список шагов проекта | отмечаешь сам |

```
├── src/                     ← код приложения (React + TypeScript)
├── scripts/
│   ├── sw.js                ← помощник офлайн-режима (шаблон)
│   ├── make-icons.mjs       ← рисует значки для сайта и Android
│   ├── generate-data.mjs    ← генератор учебных данных
│   └── fetch-pyodide.mjs    ← подготовка Python для работы без интернета

├── .github/workflows/       ← автоматическая сборка сайта и APK на GitHub

```

## Как добавить новую тему

1. Создай папку `content/<модуль>/<тема>/`.
2. Положи в неё `lesson.md` — объяснение. Блоки ` ```sql ` и ` ```python ` станут «живыми» примерами с кнопкой «Запустить». Строка `-- chart: bar` или `-- chart: line` в начале SQL-примера добавит график. Пример, который **нарочно** показывает ошибку, начни со строки `-- ⛔ …` (в Python — `# ⛔ …`).
3. Положи `tasks.json` — задания. Пример SQL-задания:

```json
{
  "id": "kazan",
  "title": "Клиенты из Казани",
  "difficulty": 1,
  "prompt": "Выведи все столбцы для клиентов из города Казань.",
  "solution": "SELECT * FROM customers WHERE city = 'Казань';",
  "hints": ["Первая подсказка", "Вторая подсказка"]
}
```

Другие типы задаются полем `"type"`: `"python"`, `"sheet"`, `"quiz"`, `"number"`, `"checklist"` — примеры есть в существующих темах.

4. Впиши тему в `content/course.json` (если её там ещё нет) и перезапусти приложение.
5. Открой служебную страницу <http://127.0.0.1:3000/?sandbox#/dev> и нажми «Проверить все задания» и «Проверить примеры из уроков». Режим `?sandbox` не трогает твой прогресс.

## Публикация и обновления

Код хранится на GitHub. При каждом обновлении ветки `main` GitHub сам (файл `.github/workflows/build.yml`):

1. собирает **сайт** и выкладывает его на GitHub Pages — у тех, кто его уже открывал, появится кнопка «Вышла новая версия курса → Обновить»;
2. собирает **APK** и выкладывает его в раздел Releases по постоянной ссылке `…/releases/latest/download/put-analitika.apk`. Новая версия ставится поверх старой, прогресс сохраняется.

**Ключ подписи APK** создаётся один раз и хранится у владельца и в секретах репозитория (`ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`). Его нельзя терять: без него новая версия не встанет поверх старой.

## Технологии

- **Vite 8 + React 19 + TypeScript 7** — само приложение;
- **DuckDB-WASM** — база данных SQL прямо в браузере (синтаксис близок к PostgreSQL);
- **Pyodide** — Python 3.14 с pandas, numpy, scipy и matplotlib в браузере;
- **HyperFormula** — движок формул для Excel-заданий;
- **CodeMirror 6** — редактор кода с подсветкой и автодополнением;
- **marked** — превращает уроки из Markdown в страницы;
- **Capacitor 8** — превращает приложение в APK для Android;
- **Service Worker** — работа сайта без интернета.

Все сервисы бесплатные, API-ключи не нужны.
