# Путь аналитика

Приложение для самостоятельного изучения аналитики данных: уроки простым языком, задания с автоматической проверкой, прогресс и план до января.

## Как запустить

**Способ 1 — двойной клик.** Открой папку `analytics-course` и дважды щёлкни по файлу `start.bat`. Откроется чёрное окно, а через пару секунд — браузер с приложением.

**Способ 2 — одна команда.** Открой терминал в папке проекта и выполни:

```
npm start
```

Приложение откроется по адресу <http://127.0.0.1:3000>.

Пока занимаешься, **не закрывай окно терминала** — это сервер приложения. Закончил — закрой окно (или нажми `Ctrl+C` в нём).

> Если PowerShell пишет, что «выполнение сценариев отключено», используй `npm.cmd start` или запускай через `start.bat`.

## Где хранится прогресс

В файле `progress.json` в папке проекта. Его можно скопировать как резервную копию. Удалишь файл — прогресс начнётся с нуля.

## Как устроен проект

```
analytics-course/
├── start.bat            ← запуск двойным кликом
├── content/             ← уроки и задания (редактировать можно без программирования)
│   ├── course.json      ← оглавление: модули и темы
│   ├── plan.json        ← план по неделям
│   ├── datasets.json    ← описание таблиц для панели «Схема данных»
│   └── sql-basics/01-select/
│       ├── lesson.md    ← объяснение (Markdown)
│       └── tasks.json   ← задания
├── public/data/shop/    ← учебные данные (CSV-таблицы)
├── scripts/generate-data.mjs ← генератор учебных данных
├── src/                 ← код приложения (React + TypeScript)
└── progress.json        ← твой прогресс (создаётся сам)
```

## Как добавить новую тему

1. Создай папку `content/<модуль>/<тема>/`.
2. Положи в неё `lesson.md` — объяснение. Блоки кода с пометкой ` ```sql ` станут «живыми» примерами с кнопкой «Запустить».
3. Положи `tasks.json` — задания. Формат одного задания:

```json
{
  "id": "kazan",
  "title": "Клиенты из Казани",
  "difficulty": 1,
  "prompt": "Выведи все столбцы для клиентов из города Казань.",
  "solution": "SELECT * FROM customers WHERE city = 'Казань';",
  "orderMatters": false,
  "checkColumnNames": false,
  "hints": ["Первая подсказка", "Вторая подсказка"]
}
```

4. Впиши тему в `content/course.json` (если её там ещё нет). Приложение подхватит её автоматически.
5. Открой служебную страницу <http://127.0.0.1:3000/#/dev> и нажми «Проверить все задания» — она убедится, что эталонные решения работают.

## Технологии

- **Vite 8 + React 19 + TypeScript 7** — само приложение;
- **DuckDB-WASM** — база данных SQL прямо в браузере (синтаксис близок к PostgreSQL), работает без интернета;
- **CodeMirror 6** — редактор кода с подсветкой и автодополнением;
- **marked** — превращает уроки из Markdown в страницы.

Все сервисы бесплатные, API-ключи не нужны.
